# E104(EG4X20BG256) ↔ ICND2260 灯板 接线与验证方案

**目的**: 在正式验证板之前, 用现成的 E104 开发板 + 现役 2260 灯板, 验掉三条纸面答不了的东西。
**日期**: 2026-09-04　**修订**: 2026-09-07

> 🔴 **2026-09-07 两处更正, 动手前先读**:
> 1. **§6 的 `FPHASE=4` 得 90° 是错的** —— 会做出差 60° 的转发时钟, 屏不亮且查不出原因。正解见 §6。
> 2. **主工作点从 166.67 MHz 改为 150 MHz**(屏侧线速率 300 Mbps 不是 333)。定案理由见
>    `dr1v90/eg4_bridge/rtl/bridge_defs.vh` §5。
>
> 台架用的**可勾选工单**(含零板改的四対全仿真接法): `E104_点亮接线单.html`。

## 0. 先做的一件事: bank1 改 2.5V

用户手册 §3.5 明确: **只有 VCCIO1 可调**(VCCIO0/2/3 固定 3.3V)。
> **拆掉 R23, 焊上 R22 即可。** 位置见 E104 的 PCB 丝印图。

电路是两只 0Ω 二选一:
```
+2.5V ──[R22  0R/NC]──┐
                      ├── VCCIO 网络 → VCCIO1 (bank1)
+3.3V ──[R23  0R   ]──┘
```
板上 +2.5V 轨来自 AMS1117(2.5V/1A), 本就是给 FPGA IO 准备的。

⚠ **bank0/bank2 不要动** —— VCCIO 是 BGA 球下打孔直连内层平面, 割不到;
且 bank0 挂着 SDRAM 与 HSWAPEN, bank2 挂着 CCLK/MSEL0 配置脚。

## 1. 信号需求 (来自现役 RTL `icnd2260_lxb_lvds_top.v`)

一颗 2260 走 mini-LVDS 需要 **4 対差分 + 3 根单端**:

| 信号 | 类型 | 说明 |
|---|---|---|
| `clk_p/n` | 差分 | 位时钟对 |
| `b_p/n` | 差分 | **D0 = SDI_B1 = lane0**, 兼发配置与 VHEAD |
| `g_p/n` | 差分 | D1 = SDI_G1 = lane1 |
| `r_p/n` | 差分 | D2 = SDI_R1 = lane2 |
| `sync` | 单端 | I_SYNC, LVDS 模式下每帧翻转一次 |
| `ack` | 单端 | ACK_O 回读, 需上拉 |
| `dclk` | 单端 | TTL 时钟, **LVDS 模式恒 0** |

🔴 **第一通道是 D0 = SDI_B1(B 対), 不是 R**。手册 §3 传输模式表的"寄存器配置"列:
TTL 走 SDI_R1, mLVDS 一律走 D0IP/N。这条踩过。

## 3. E104 侧引脚分配

### 方案: 时钟走真差分, 三个数据対走仿真

理由: 时钟对共模精度最要紧, 真差分能设 `VCM=1.2` 精确;
数据対用仿真 5R 网络, 正好把两种驱动方式在同一颗芯片上对比。

| 2260 信号 | **E104 排针** | FPGA 球位 | 类型 | bank | VCCIO |
|---|---|---|---|---|---|
| `clk_p` | **J4.16** | J13 (`L14P_GCLKIOL5_1`) | **真差分** | 1 | 2.5V |
| `clk_n` | **J4.15** | K14 (`L14N_GCLKIOL4_1`) | **真差分** | 1 | 2.5V |
| `b_p` (D0) | **J4.58** | B12 (`BE16P_0`) | 仿真 +5R | 0 | 3.3V |
| `b_n` (D0) | **J4.57** | A12 (`BE16N_0`) | 仿真 +5R | 0 | 3.3V |
| `g_p` (D1) | **J4.56** | C13 (`BE17P_0`) | 仿真 +5R | 0 | 3.3V |
| `g_n` (D1) | **J4.55** | A13 (`BE17N_0`) | 仿真 +5R | 0 | 3.3V |
| `r_p` (D2) | **J4.54** | B14 (`BE19P_0`) | 仿真 +5R | 0 | 3.3V |
| `r_n` (D2) | **J4.53** | A14 (`BE19N_0`) | 仿真 +5R | 0 | 3.3V |
| `sync` | **J4.50** | B15 (`L2P_1`) | LVCMOS25 | 1 | 2.5V |
| `ack` | **J4.49** | B16 (`L2N_1`) | LVCMOS25 上拉 | 1 | 2.5V |
| `dclk` | **J4.48** | C15 (`L6P_1`) | LVCMOS25 恒 0 | 1 | 2.5V |
| **GND** | **J4.59 / J4.60** | — | — | — | 紧邻时钟対 |
| **GND** | J4.41 / J4.42 | — | — | — | |

### 为什么这么挑

**时钟対选 J4.15/16** —— 那是 `GCLKIOL4/5` **专用时钟脚**, bank1 可改 2.5V 用 `LVDS25` +
`VCM=1.2` 精确设共模; 走线 1492.96/1493.66 mil, 対内失配 0.7 mil。
⚠ 极性: **J4.16 = L14**P** = `clk_p`**, J4.15 = L14**N** = `clk_n`。排针奇偶与 P/N 不对应, 别搞反。

**数据対选 J4.53~58 连续三対** —— 全在 bank0, 排针上**连号相邻**, 飞线最短、最不易接错:
```
J4.58 J4.57 | J4.56 J4.55 | J4.54 J4.53
  D0(b)     |   D1(g)     |   D2(r)
```

**🎯 比原计划多找到两対仿真対**: 除了 `BE16`/`BE17`, J4.51~54 还有
`BE20`(D12/D11, `GPLL0_OUT`) 与 `BE19`(A14/B14, `GPLL0_CLKIN`)。
⇒ **bank0 在 J4 上共有 4 対连续仿真対(J4.51~58)**, 加 bank2 的 `TE8`(J4.3/4) 与
`TE13`(J3.13/14) = **共 6 対仿真対可用**, 比原来数的 4 対多。
⇒ 若想**全仿真対驱一颗 2260**(时钟也走仿真), 用 J4.51~58 四対即可, 完全不碰 bank1。

⚠ `BE19`/`BE20` 复用 `GPLL0_CLKIN`/`GPLL0_OUT` —— 作普通 IO 用时要确认 PLL0 没被占用。
若冲突, 退回用 `TE8`(J4.3/4) 做 D2。

**地**: J4.59/60 与 J4.41/42 是 GND(原理图 `PIJ4059/PIJ4060/PIJ4041/PIJ4042`)。
时钟対 J4.15/16 离最近的地(J4.19/20)有 3 脚 —— **飞线时每対自己带一根地回来**,
别指望排针上的地脚。踩过「J1.21/22 紧邻无地 ⇒ DCLK 串扰拽出 5 万假帧」。

### J4 排针全貌 (56 脚有约束)
- **J4.1~2, 19~20, 41~42, 59~60** = GND
- **J4.3~4** = `TE8` 仿真対 (bank2)
- **J4.5~50** = bank1 真差分, 共 21 対 (含 J4.15~18 两対 GCLKIOL 专用时钟脚)
- **J4.51~58** = bank0 仿真対 ×4

## 4. 🔴 5R 电阻网络 (仿真対专用)

### 为什么要 5R 而不是手册的 3R

仿真 LVDS 是 **CMOS 驱动 + 电阻网络**, 共模天然 = **VCCIO/2**:
- VCCIO 2.5V → 共模 **1.25V** ✅ 落在 2260 的 `VIC` 1.1~1.3 窗内(最终板就是这样)
- VCCIO 3.3V → 共模 **1.65V** 🔴 出窗

E104 的 bank0/2 焊死 3.3V ⇒ 必须**每腿加一只对地电阻 Rpd 把共模拉下来**:
```
VCM = (VCCIO/2) × Rpd / (Rpd + Rout + RS)      Rout = 10Ω (TN309 注1)
```

### 推荐值 (每个数据対 5 只电阻)

```
            RS=150            
FPGA P ──[150Ω]──┬──────────────┬────── 2260 RXP
                 │              │
              [430Ω]         [140Ω] RP
                 │              │
                GND             │
                                │
FPGA N ──[150Ω]──┬──────────────┴────── 2260 RXN
                 │
              [430Ω]
                 │
                GND
```

| 参数 | 值 | 来源/结果 |
|---|---|---|
| `RS` | **150 Ω** | UG303 表 3-1 / TN309 表 4-2 的 150/140 档 |
| `RP` | **140 Ω** | 同上 |
| `Rpd` | **430 Ω** (E24) | 本方案计算 |
| ⇒ 共模 | **1.203 V** | ✅ 2260 `VIC` 1.1~1.3 正中 |
| ⇒ 幅值 | **约 432 mV** | ✅ `VID` ±100~±600 内, > `VTH` 100mV; 低于 500mV 门槛可用片内端接 |
| 差分衰减 | 10.5% | 两只 Rpd 串联 = 860Ω 跨接, 与 100Ω 端接并联 → 89.5Ω |

🔴 **RS 与 Rpd 必须配对**: 同样 430Ω 配 RS=210 共模掉到 1.092V **出窗**。别混档。

其它档位备选:
| RS | RP | Rpd | 共模 | 幅值 |
|---|---|---|---|---|
| 300 | 118 | 827 | 1.2V | 241 mV |
| 210 | 127 | 587 | 1.2V | 327 mV |
| **150** | **140** | **430** | **1.203V** | **432 mV** ← 推荐 |
| 115 | 160 | 333 | 1.2V | 530 mV (>500, 要片外端接) |

### 端接
灯板**板上无端接**, 所以 100Ω 差分端接要自己加, 焊在**灯板侧**(尽量靠近 2260)。
真差分那对(时钟)可用 FPGA 片内端接 —— 实测 TD 对 LVDS **输入**自动开 `DIFFRESISTOR:100`,
但**输出**方向要在灯板侧加。

## 5. TD 侧 `.adc` 约束

```tcl
## --- 时钟対: 真差分, bank1 @2.5V, VCM 可设 ---
set_pin_assignment { clk_p } { LOCATION = J13; IOSTANDARD = LVDS25; VCM = 1.2; VOD = 350m; SLEWRATE = MED; }
set_pin_assignment { clk_n } { LOCATION = K14; IOSTANDARD = LVDS25; VCM = 1.2; VOD = 350m; SLEWRATE = MED; }

## --- 数据対: 仿真, bank0/2 @3.3V, 外接 5R ---
## 🔴 绝对不要给仿真対写 VCM —— 实测不报错但会真写进 bank 配置, 与手册矛盾
set_pin_assignment { b_p } { LOCATION = B12; IOSTANDARD = LVDS33_E; }
set_pin_assignment { b_n } { LOCATION = A12; IOSTANDARD = LVDS33_E; }
set_pin_assignment { g_p } { LOCATION = C13; IOSTANDARD = LVDS33_E; }
set_pin_assignment { g_n } { LOCATION = A13; IOSTANDARD = LVDS33_E; }
set_pin_assignment { r_p } { LOCATION = B14; IOSTANDARD = LVDS33_E; }
set_pin_assignment { r_n } { LOCATION = A14; IOSTANDARD = LVDS33_E; }
## 备选 D2(若 BE19 与 PLL0 冲突): R9/T9 = TE8, 在 bank2, J4.4/J4.3

## --- 单端控制: bank1 @2.5V ---
set_pin_assignment { sync } { LOCATION = B15; IOSTANDARD = LVCMOS25; DRIVESTRENGTH = 8; SLEWRATE = FAST; }
set_pin_assignment { ack  } { LOCATION = B16; IOSTANDARD = LVCMOS25; PULLTYPE = PULLUP; }
set_pin_assignment { dclk } { LOCATION = C15; IOSTANDARD = LVCMOS25; DRIVESTRENGTH = 8; }
```

⚠ **`VCM`/`VOD` 是 per-bank 不是 per-pin** —— 同 bank 给两个不同值会报
`USR-8001 ERROR: Design contains multiple VCM setups on bank N`。
⚠ **`PREEMPHASIS` EG4 不支持** —— `USR-8409 ERROR: PREEMPHASIS is not supported by IOBE.LVDS25`。
⚠ `LVDS33_E` 工具接受到 bit, 但 **DS300 表 3-2-5 的输出频率表里只有 LVDS25E**;
   TN309 表 4-2 与 UG303 表 3-1 给了 LVDSE33 幅值列。⇒ **存在但无频率背书, 166MHz 能否跑正是要测的**。

## 6. 源同步时序 (照搬现役, 别改)

> mini-LVDS 的 `tSTU/tHLD` = **1/4 tLVCP** (DS V1.7) ⇒ 芯片在**位中间**采样
> ⇒ **转发时钟必须比数据晚 90°**

Xilinx 版用 MMCM `CLKOUT1_PHASE=90` 实现。EG4 上对应手段:
`EG_PHY_PLL` 的 `CLKCx_CPHASE`(步长 1 个 VCO 周期) + `CLKCx_FPHASE`(步长 1/8 个 VCO 周期, 合法 [0,7])。

🔴🔴 **2026-09-07 更正: 原文"90° 需要 FPHASE=4(4 × 22.5°)"是错的, 照它做转发时钟会差 60°。**
「22.5°/步」只在输出分频比 `DIV = 2` 时成立。本设计 dclk 由 `VCO/6` 出 ⇒ **一步只有 7.5°**,
`FPHASE=4` 只有 30°。通式(CD = 输出分频比):

```
90° of dclk = CD/4 个 VCO 周期 = (2 × CD) 个 1/8-VCO 单位
  CPHASE = (CD - 1) + (2×CD)/8        FPHASE = (2×CD) % 8
  CD=6 → CPHASE 6 / FPHASE 4      CD=5 → 5 / 2      CD=7 → 7 / 6      CD=8 → 9 / 0
```

【TD 实证】`create_generated_clock ... -phase 90`; Clock Summary `dclk90 Rise 1.666 / 周期 6.666 = 90.0°`。
实现见 `dr1v90/eg4_bridge/rtl/bridge_clk.v` 的 `SC_C2_CPH` / `SC_C2_FPH`(已按通式写)。

🔴 **这跟 TTL 版的"边沿对齐"要求正好相反, 别把两份约束混用。**

## 7. 四个实验

| # | 实验 | 用什么 | 判据 |
|---|---|---|---|
| ① | **量 VCM 三档实际共模** | bank1 真差分対 + 示波器 | 设 0.8/0.9/1.2 各量一次, 看实测值与容差 |
| ② | **真差分驱 2260 @332 Mbps** | bank1 的 4 対全用真差分 | 屏亮 + ACK 回包 |
| ③ | **800M 上行环回 + 眼图** | bank1 真差分自环 | PRBS 误码率, 眼图 |
| ④ | ★ **仿真対 5R 驱 2260 @150 MHz** | 本文档的接法 | 屏亮 + ACK 回包 |

**④ 是最值钱的** —— 最终屏板下行 73 対里有 **51 対是仿真対**, 而"电阻网络驱动的信号
2260 认不认"纸面上零背书。建议先做 ② 建立基准(真差分能亮), 再做 ④ 对比。

### ④ 测到与没测到
| ✅ 测到 | 🔴 没测到 |
|---|---|
| CMOS 驱动 + 电阻网络能否在 150MHz 驱动 2260 | LVDS25E 在 VCCIO=2.5V 下的原生行为 |
| 电阻网络的 SI、上升沿、抖动 | 3R(而非 5R)的实际衰减 |
| 2260 能否接收这种非标准 LVDS | |

最终板换成 LVDS25E + 3R 只是**把 Rpd 拿掉、共模由 VCCIO/2 天然给定**, 是更简单的配置。

## 8. 器材清单

- E104 开发板 (EG4X20BG256) ×1
- 现役 2260 灯板 (9 颗级联, 40×45) ×1
- 电阻: `150Ω` ×6, `140Ω` ×3, `430Ω` ×6 (三个数据対), 精度 1%
- `100Ω` 差分端接 ×4 (焊灯板侧, 靠近 2260)
- 排线/杜邦线, 尽量短且等长
- 示波器 ≥1 GHz 带宽 (看 332 Mbps 眼图)
- 万用表 (**接线前先量 J1.1/J1.16 电源, 曾经接反过**)
