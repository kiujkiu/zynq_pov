2026-09-08 勘误与补充（驱动工程建好之后） ① 转发时钟対的球号原先写反了（已改）。 原理图第 9 页 J4 网表原文： D11_BE20P_GPLL0_OUTP_0 → PIJ4052、D12_BE20N_GPLL0_OUTN_0 → PIJ4051 ⇒ J4.52 = D11 = P、J4.51 = D12 = N。 🔴 J4 脚号没变，「偶数脚 = P」这条规则也没错，只是球名写反 ⇒ 已焊的线不用动。 影响的只是 .adc（差分只能约 P 端，写错会 Error-8066 白跑一轮），工程里已按 D11 写。

🔴 2026-09-08 定案：焊 5R，不改板电压。三条替代路都算过了，都不划算 ① 拆 SDRAM 改 VCCIO0？不行。 根因不是 SDRAM 占着 3.3V，是电压平面本身改不了： 用户手册 §3.5 明写「只有 VCCIO1 可调，VCCIO0/2/3 固定 3.3V」； VCCIO0 只有一个球 B13，BGA 球下打孔直连内层平面，刀片割不到， 也没有 R22/R23 那样的二选一 0Ω。bank0 还挂着 HSWAPEN，不只 SDRAM。
② 全板 3.3V 改 2.5V？收益只有 8 只电阻，代价是赌一个未知件。 ✅ 查证 VCCAUX 可以 2.5V（DS300 直流工作条件：2.375 / 2.5或3.3 / 3.63 V，原以为是死结，不是）； ✅ 板上本就有 +2.5V/1A 轨（AMS1117-2.5, U7）。但： AMS1117-3.3(U6) 是固定输出要换件；拆 U6 跳线则 U7 一颗 1A 要扛原来两路负载，余量存疑； SPI flash W25Q16JVSIG 规格 2.7~3.6V，2.5V 低于下限； 🔴 50 MHz 振荡器 Y1 原理图没给型号，电压范围未知 —— 它不工作整板没时钟，是单点故障。

为什么共模能对上、差分要小心 共模：RP 两端等电位 ⇒ 共模下不载流；Rct 在中点 ⇒ 差分下是虚地。 两个拓扑的共模等效电路本来就是「源阻抗 80 Ω 串一个对地负载」，负载相同则共模相同。
🔴 差分则不然：现方案里两只 Rpd 串联（860 Ω）也跨在 P–N 上，是差分负载的一部分； 而变体的 Rct 是虚地，一点差分负载都不贡献。 ⇒ 拆一半必须取 62 Ω 而不是 68 Ω，否则幅值多出 4.7%，会吃掉「幅值 < 500 mV 才能用片内端接」那条余量。
数学上最完美的是 60 + 185（共模 215.0 Ω 与现方案逐位相同、差分 −0.1%）， 但 60 与 185 都不是 E24（要 E96 的 60.4 / 187）⇒ 实用上取 62 + 180，两个都是 E24。

为什么是 62 不是 68 —— 共模和差分要分别算，而 Rpd 同时出现在两条路径里

取半值时最容易犯的错，是把差分目标当成 RP = 140 Ω。不是。 现方案里两只 Rpd 串联（430+430 = 860 Ω）也跨在 P–N 之间 —— 从 P 经 Rpd 到 GND、再经另一只 Rpd 到 N，是一条实实在在的电阻通路。 接线方案 §4 的参数表自己写着：「两只 Rpd 串联 = 860 Ω 跨接」。 ⇒ 真正的差分目标是 140 ∥ 860 = 120.4 Ω，不是 140。

这条演示的通用规则 共模路径与差分路径要分别算，同一只电阻可能同时出现在两条里、权重还不一样。
· RP：共模下两端等电位 ⇒ 不载流，只进差分账。
· Rct：差分下中点是虚地 ⇒ 不载流，只进共模账。
· 🔴 Rpd：两条账都要进 —— 共模看 430∥430 = 215 Ω，差分看 串联 860 Ω 跨接。
漏掉最后这条，就会把差分目标当成 140 而选出 68。

02

第二步：改板（只有做真差分对照才需要）

要动焊台

第一步已经能回答最值钱的问题。只有当你要量 VCM 三档实际共模、或用真差分建立"能亮"的基准时，才需要动板子。

🔴 改之前先确认：这一改可能让 JTAG 下不进去 X20 的 JTAG 四脚跨两个 bank：TCK(C14)/TDI(C12) 在 bank0，TDO(E14)/TMS(A15) 在 bank1。 而 DS300 表 3-1-5 对 EG4X20BG256 的 VCCIO0 与 VCCIO1 都写着「≥ 下载器供电电压，如果使用 JTAG 下载，需要和下载器供电电压保持一致」。 E104 只能改 VCCIO1 ⇒ 改完两个 JTAG bank 电压不一致。
⇒ 动烙铁前先查两件事：① E104 实际用什么下载（用户手册写默认 MSPI，另有 Slave Serial）；② 下载器 J2.4 的 VREF 是取板上电压还是固定 3.3 V。 准备好退路：改完立刻验一次能否识别/下载，不行就焊回 R23。这条是 A20 上不存在的，只有 X20 有。
bank0 / bank2 绝对不要动 它们的 VCCIO 是 BGA 球下打孔直连内层平面，割不到；而且 bank0 挂着 SDRAM 与 HSWAPEN，bank2 挂着 CCLK/MSEL0 配置脚。动了这块板就废了。

05

实验 ⑤：PLL refclk 能不能吃 400 MHz（🔴 唯一还能推翻引脚定案的未知数）

为什么必须验：上行转发时钟 2026-09-07 定案走 PLL（方案 A）—— DR1 发 400 MHz 半速时钟 → REFCLK_DIV=4 → PFD 100 → VCO 800 → sclk 400 / pclk 200。 但 EG_PHY_PLL 的 refclk 输入脚能不能吃 400 MHz，手册与原语里都查不到出处 （只有 VCO 300~1200、fOUT ≤ 400，没有输入脚范围；FIN 在 eagle_macro.v 里 只是个没被模型用到的注解字符串）。这条不结，PCB 上转发时钟対怎么走就是悬的。

✅ 结论：E104 做得了，而且不用改板 —— 只在 J4 排针上飞一根短线。

为什么不用改板

  • PLL 的专用时钟脚在 E104 上引出来了：BE19(A14/B14) = GPLL0_CLKIN、 BE20(D11/D12) = GPLL0_OUT，都在 J4、都在 bank0。 这是专用 PLL 时钟输入脚，比 GCLKIOL 更直接（后者是否能进 PLL refclk 无需再问）。
  • SDRAM 占的是 bank0 的 GCLKIOB（BE9~BE12），不是 BE19/BE20 —— 这两対没被占。
  • 全程不动 VCCIO1：实验只用 bank0（焊死 3.3V）。⇒ 绕开 「改 VCCIO1 到 2.5V 可能让 JTAG 下不进去」那条 X20 独有的风险。
  • 管脚分配图确认 B14/A14 与 D11/D12 在 J4 上相邻 ⇒ 飞线只有几毫米， 400 MHz 的信号完整性压力很小。

怎么接（一対飞线，不是一根）

板载晶振 = 50 MHz，在球 H3（原理图网名 H3_50MHz_CLK）。50 恰好在 FIN 查找表 {25,50,100} 内，不用放宽任何断言。

🔴 发送侧必须走 bank1 的真差分対、用 LVDS33，不能单端也不能用仿真対：

  • 仿真対（BE*）输出上限只有 166 MHz（DS300 表 3-2-5 只给了 LVDS25E 一行， 166 MHz），单端 LVCMOS33 更低 ⇒ 400 MHz 出不来。
  • LVDS33 真差分输入输出都是 400 MHz / 800 Mbps（DS300 表 3-2-5）⇒ 够用。
  • 接收侧反而没问题：BE19 虽是仿真対，但 DS300 明写 「真/仿真対均可作 LVDS25 标准输入，最大 400 MHz」——"仿真"只在发送侧有意义。
H3 (50 MHz 板载晶振)
  └─> PLL_A:  FIN=50  REFCLK_DIV=1  FBCLK_DIV=8  CLKC0_DIV=2  => VCO 800, C0 = 400 MHz
        └─> ODDR (d1=1,d0=0) ─> bank1 一対真差分, IOSTANDARD = LVDS33
              例: B15/B16 = L2P_1 / L2N_1   (⚠ 是**一対差分**, 不是两个单端脚)
              └── 飞线一対 (短、等长、带一根地回来) ──> A14/B14 = BE19N/BE19P = GPLL0_CLKIN
                    └─> PLL0:  refclk = 400 MHz, REFCLK_DIV=4 => PFD 100
                               FBCLK_DIV=4, CLKC0_DIV=2 => VCO 800 => C0 400 / C1 200

⚠ 别用 D11/D12 当发送脚：BE20 = GPLL0_OUT 是 PLL0 的专用输出， 而本实验正用 PLL0 当接收端，可能冲突。

🔴 实验 ⑤ 与「四対全仿真驱 2260」不能同时接。 BE19/BE20 在接线方案第 3 节里是候选数据対 D2；实验 ⑤ 把 BE19 占去当 PLL 输入 ⇒ 两个实验要分开做，别以为能一次接完。 要同时做的话，D2 退回用 bank2 的 TE8(J4.3/4)。

判据

  1. PLL0.extlock 拉高 —— 这就是「400 MHz 进得了 refclk」的直接答案。
  2. PLL0 的输出频率对得上：C0 应为 400 MHz、C1 应为 200 MHz。 只看 extlock 不够 —— 锁在错误的分频比上 extlock 照样会高，必须独立测频。两种做法：
    • 示波器法：把 C1(200 MHz) 用一个 ÷N 计数器降到 1~10 MHz， 从 bank1 一対 LVDS33 出去量。别直接量 400 MHz，探头和飞线会骗你。
    • 数秒法（不用示波器，更硬）：用 H3 的 50 MHz 做基准数 1 秒（50,000,000 拍）， 同一秒内数 C1 的边沿数，读数应为 200,000,000 ± 少量。 结果用 LED 二进制点出来或走 UART。这个法子不依赖任何量具的带宽。
  3. 失败的话记下失败方式：完全不锁 / 锁了但频率不对 / 锁了但抖动大。 三种对应的退路不同。
