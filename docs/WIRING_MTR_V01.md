## 其他
| 用途 | J1 |
|---|---|
| 光电开关信号 SPIN_SYNC | **34** (V14, FPGA 内部上拉) |
| 光电开关电源 3.3V | 37/38 |
| GND (面板逻辑地/传感器地) | 35/36 |
| +5V (风扇等) | 39/40 |
| **不要接** (转接板 U1 DIR 位) | 33 |
| 空闲 | 1/2/3/4 (L2N/L2P/L3N/L3P) |

## 注意
1. GPIO1 电源端在 35-40 (GND 35/36, 3V3 37/38, 5V 39/40); pin 1-4 是信号 L2/L3
2. 面板色序 (P1 GRB / P2 BRG) 这次**不做物理换线** — 直通接, 上电后 RGB 测试卡标定, 在 XDC 里吸收
3. 面板 5V 大电流供电照旧走独立电源, 不走 GPIO1
