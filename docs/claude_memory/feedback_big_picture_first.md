跟用户讨论"下一步做什么"、汇报进度时，先用大功能、里程碑的话来说（屏幕显示 / 桥片 / 远程升级 / 整机转起来这类），不要一上来就堆任务编号、寄存器值、签名、提交哈希。

**Why:** 2026-10-12 用户原话: "我们这样，说大的功能，我好理解，现在我们下一步做什么"。当天汇报里 1.3.x 编号和技术细节太多。

**How to apply:** 先给一张"整体进度/下一步"的大图（每块一句话 + 卡在什么上）。细节只在用户追问或需要拍板时给。agent 的技术汇报照常收，但转述给用户时提炼成大功能语言。相关: [[feedback-pov-in-subagent]]。
