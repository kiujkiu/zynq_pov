---
name: pov_rxd 不支持多客户端并发, 两路同推丢帧 45%
description: bank A/B 是双缓冲翻页不是客户端隔离; 两台机器同时推会互相覆盖同一 DDR
type: feedback
---
2026-07-28 实测: 两台机器 (10.10.20.125 + 10.10.20.193) 同时连 `pov_rxd:9500` 推流:

```
ESTAB 10.10.21.3:9500 ← 10.10.20.125:64516
ESTAB 10.10.21.3:9500 ← 10.10.20.193:7306   Recv-Q 46136   ← 积压
STAT rx=44756 flip=24689 drop=20067          ← 丢帧率 45%
```
停掉其中一路后 `drop` 立即冻结不再增长, 收发一一对应 (`rx +152 / flip +152 / drop +0`)。

**根因**: bank A/B 是给**双缓冲翻页**用的 (一个显示、一个接收), **不是客户端隔离**。
两路同时推 → 抢同一块 DDR 互相覆盖 → 屏上是两路交替混合的画面。

**判据**:
- `ss -tn | grep 9500` 看到**超过一个 ESTAB** 即是此问题
- `pov_rxd.log` 的 `drop` 持续增长 (单客户端应为 0)

**How to apply**: 排查"画面不对/闪烁/内容混乱"时**先查连接数**, 别一头扎进渲染参数。
今天就因为没先查, 一度以为是几何或镜像的问题。

若将来要支持多机: 需加客户端仲裁 (只接受第一个连接、后来者拒绝) 或内容合成, 属独立改造。
