# 位"改义"让屏静默降速一个月 (2026-08-10 查实, 事发 2026-07-14)

`pov_boot.sh:38` 写 `0x0C = 0xB8366F01`，其中 **bit29 = 1**。现役 Zynq 因此大概率
一直跑在 **25 Mbps 降级模式 / 面板刷新 2393 Hz**，而所有性能账都按 4748 Hz 算。

## 不是手误, 是位语义反转

| 时间 | 事件 |
|---|---|
| 07-09 | `pov_boot.sh` 首次写这个值。当时 RTL 是 v5 `icnd2049_panel_pov.v:31`，那里 bit29 = `dclk_fast`(**1 = 全速**) ⇒ **当时写得完全正确** |
| 07-14/15 | 换 2047 双沿核。同一位反转成 `ddr_slow`(**1 = 降级**)。`panel_engine_2047.v:74` `.ddr_slow(dclk_fast)  // 位改义` |
| 08-01 / 08-03 | `pov_boot.sh` 又改过两次(地址表、oe 192→111)，**每次都原样带着 `B8`** |

⇒ **一个曾经正确的常量，因为别处的改动而变成错的，而它自己一个字节都没动。**
git blame 指向 07-09 那次正确的提交，查改动历史找不到"谁把它改错的"——**没有人改错，是它脚下的地基被换了。**

## 为什么一个月没被发现

**回读只能证明"写进去了"，不能证明"它现在是什么意思"。**
`dclk_fast` 这个触发器同时接到 status bit7，回读一切正常 —— 值确实是 1，
而 1 在新 RTL 里就是降级。所有的自检都通过了，因为自检问的是错的问题。

设计文档**预判到了这个坑**：`docs/design_icnd2047/01_rtl_ddr_engine.md:282` 明写
「旧 0x0C 写脚本若带 bit29=1 现在会进 ddr_slow 半速」，`:320` 风险 R9 的缓解措施是
「R 0x20 frame_period 一读便知」。
🔴 **但那个回读口最终没引出** —— `panel_engine_2047.v:97` `.frame_period_o ()` 空着，
`pov_dual_top.v:59` 只是"特意留空规划给它"。
**预警写了，兜底没做，坑照踩。**

## 可推广的

1. **配置回读 ≠ 行为验证。** 回读配置寄存器只关闭"写丢了"这一种失败，
   关不掉"语义变了""位没接""下游忽略它"。
   ⇒ **每个影响性能/正确性的配置，都要有一个测真实行为的口**
   （这里就是 `frame_period`：一读就知道真实刷新率，这类事一秒结案）。
   这条与 [[feedback_verify_signal_actually_connected]] 是同一族。
2. **"位复用改义"应当视为破坏性变更。** 真要改义，至少同时改位号或改寄存器地址，
   让老脚本**报错**而不是**静默跑另一个模式**。沉默的兼容比不兼容更贵。
3. **换 RTL 时要审的不只是 RTL。** 板端脚本里的魔数常量是 RTL 的隐式调用方，
   它们不在编译期检查里，也不在 git diff 的视野里。
4. **一个数字如果任何脚本都产生不了它，它就不是现役数字。**
   最后是这么定死的：`4748 Hz = fast + oe111`，而仓库里没有任何脚本产生这个组合
   （`pov_boot.sh` 是 slow+111 = 2393，`pov_boot_v3fs03.sh` 是 fast+187 = 3417）。
   **不管板上跑哪个，4748 都是错的** —— 这个论证不需要连上板子。
   ⚠ 而产出那张 4748 表的 `sim/tb_oe_sweep.v:42` 是 `.ddr_slow(1'b0)` 硬接地：
   **仿真只覆盖了一半状态空间，那张表从头到尾只测了 fast。**

## 同一天在 DR1 上撞到的同族问题

`td_pov/.../pov_dr1_top.v` 的调试窗口**读通路做了隔离，写通路没有**：
`lite_awvalid` 直连 `pov_dual_top`，而它的译码**不看 addr bit14**
⇒ **写 `0x8000400C` 同时就是写 `pov_dual_top` 的 `0x0C`**，
`wdata[31:30]=00` 会清掉 `sdi_mask`(关屏 lane)、`=11` 会开自测图案。
唯一安全值是 `[31:30]=01`。⇒ 那个调试计数器**只读不清零**。

⇒ 这两件事是同一个设计习惯的两个出口：**地址/位被复用，而复用没有被隔离或标记。**
