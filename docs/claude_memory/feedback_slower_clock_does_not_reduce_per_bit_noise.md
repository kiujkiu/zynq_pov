# "慢时钟顺带降噪声"是错的 (2026-09-02, ICND2260 九颗级联)

## 我说错的话

div48(20.8MHz) 比 div16(62.5MHz) 可靠得多。我给用户的解释是:
「慢时钟同时压了两样东西 —— 时钟树偏斜(±37°→±12.4°)**和开关噪声(约 1/3)**」。

🔴 **后半句是错的。**

- LED 峰值电流由 `0x2d/0x3d/0x4d` 的 `IREF × (igain+1)` 和灰度占空比决定,
  **与 DCLK 完全无关**。
- 按**每秒**算, 慢时钟的开关事件确实少 3 倍; 但**误码率是按位算的**,
  每传输一位所承受的扰动幅度**一模一样**。

## 正确的框架

```
失效判据 = 扰动幅度(固定 ns / 固定 mV) ÷ 眼宽(∝ tLVCP)
           ↑ 地弹、PCB偏斜、芯片抖动底噪    ↑ 只有 DCLK 能动
```

**"位周期"和"噪声"不是两个并列候选, 是同一个比值的分母和分子。**
降 DCLK 只动分母。要动分子只能从电流/去耦/地平面/布局下手。
⇒ 排查时不要把它们当成两条要互相区分的假设, 要区分的是"这条比值轴" vs 其它轴(等待时间等)。

## 可推广的

**"改了 A 之后好了"不等于"A 的每一个伴随效应都在起作用"。**
列出 A 改变的所有量之后, 还要逐个问: **这个量真的变了吗? 按哪个单位算?**
我这次就是把"每秒的噪声事件数"当成了"每位的噪声幅度"。**单位错了, 结论就错了。**
