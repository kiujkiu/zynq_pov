用户 10-13: "dr1m90 推送到 gw5a 然后由 gw5a 控制 2260 这个部分我们统称为屏幕显示…在屏幕显示之前的部分可以兼容, 后续只换这个显示, 这样切割会让工作复用程度高一点"。主会话同意并细化:

- **公共部分**: 主机内容+实时推流、WiFi、板上收包/散写网格/双缓冲翻页、LUT 机制 (参数随屏换)、PL 切片器、转速同步与角度时序、遥测/运维/远程升级。
- **显示后端**: 颜色处理 (2047: sub3/γ/抖动/3-bit; 2260: γ→12 bit/通道)、面板坐标映射、传输 (2047 直驱; 2260 格式器+上行+GW5A+2260)、补片。
- **接口 = 实时按角度片流** (片号/面/圈号 + 一片 RGB565 列 + 有效/迟到/掉片标志), 由显示侧角度时序驱动。契约由 task/pls-2047 起草写进 slice/INTEGRATION.md。
- 推论: 2047 也改走实时片流 (原 "按内容帧批量切写帧 bank" 方案作废, 10-13 已通知 pls-2047 agent), 这样 0 期转起来就在验证 2260 要用的实时切片路径。
- 硬件注意: SoC 转接板要求 FS03 bank33/bank11 改 2.5V, bank11 改后 2047 屏不能再接 CEP2 ⇒ 0 期 2047 台架和 1 期转接板最好用不同的 FS03 板。

**How to apply:** 新功能先判断属于公共部分还是后端; 后端只能经片流接口和公共部分交互。相关 [[project-sw-three-phases-1013]] [[project-short-term-delivery-1013]]
