# X1: DR1M90 DDR 双口并发切片读效率 (2026-10-10)

量具 `dr1v90/measure/07_eta_m90/` (PL 读引擎 hclk=200 MHz 实测 200.02, AXI3 64 bit, 只读;
`host/load_eta.sh` + `host/eta`), 原始输出 `results/2026-10-10.txt`, 详表 README.md。

- 单口: 切片 1556 MB/s = 口峰 1600 的 97%, 每片 53.3 µs。
- **双口 ot=8: 893+893 = 1786 MB/s, η = 0.837; 每片均 92.9 µs, 最慢片 95–98 µs**; 30000 片长跑最慢 133 µs。
- 连续读双口也只有 1789 ⇒ 天花板与图样无关; 同基址同体素 (=7020 测法) 也一样。
- DDRC PSTAT 0xF84213FC 双口跑时只亮 bit2 ⇒ **HP0/HP1 都进 DDRC 端口 2**, 互抢 —— 支持厂商"按地址"说法, 推翻 UG1214 "XPI3=HP1"。
- ot ≥ 4 饱和 (ot 1/2/3 合计 716/1335/1719), 最佳 5–8 无差。
- 判据: 均值裸过 (余 2%), 逐片/留 20% 都不过。对 7020: η 0.950 → 0.837, 81.9 → 92.9 µs。

**How to apply:** 1050 RPM 目标板在 M90 上只能"平均刚够": 取片要有片间 FIFO 吸抖动, CPU 侧
DDR 流量必须压住; 要 20% 余量得降转速 (≈ 890 RPM 以下) 或减每片字节 (8-bit 调色板/列复用), 或想办法让 HP1 走另一个 DDRC 口。
