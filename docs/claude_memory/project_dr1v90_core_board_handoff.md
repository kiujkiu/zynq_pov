## 🔴 自研理由收敛成三条 —— 全在板级, 芯片本身够用

| # | FS03 的限制 | 芯片实际能力 |
|---|---|---|
| 1 | **没有 2.5V 轨** ⇒ 只能 LVDS18, VOCM 典型 **0.6V** | LVDS25 VOCM 典型 **1.25V** |
| 2 | DDR **只贴 1 片 16bit** | **32bit(DQ0~31, 4 lane) / 最大 1GB** |
| 3 | 连接器只引出 **96 根 = 48 対** | **96 対真差分** |

**第 1 条这次闭环了**(此前只是"VOCM 典型值正中、两端超窗"的悬案):
直接核两边手册 —— DR1 LVDS25 `VOCM` **0.9/1.25/1.4V**(DS1200 表 3-14) vs
ICND2260 `VIC` **1.1~1.3V**(datasheet V1.7 第 390–393 行, 典型 1.2V) ⇒ **典型值落窗内**;
LVDS18 的 0.3/0.6/0.8V **完全在窗外**。⇒ **自研板必须有 2.5V 轨, 这是第一位的电源需求。**
⚠ 但规格两端(0.9/1.4)仍超窗, 且 FS03 上实测共模 1.294V **离上限只剩 6mV**
⇒ **每条 LVDS 链路要留 AC 耦合 + 共模偏置的位置**(UG1210 §2.6.4, 电容 0.01~0.1µF), 默认可不贴。

## 逐球比对的产出(484 球, 机器比 PINLIST vs DS1200 §4.3)

- **总账**: 63 GND + 1 GNDADC + 68 电源 + **200 PL IO** + 57 PS IO + 75 PS DDR
  + 4 JTAG + 3 CONFIG + 3 RSV + 6 NC + 4 ADC 专用 = **484**
- **PL 四个 bank 完全对称**: 每 bank **24 対真差分 + 2 单端**, 合计 **96 対**, **无伪差分対**
- 每 bank **4 対 GCLK**; **16 路 ADC 全复用在 bank33**
  (⚠ DS1200 §4.2 那三条限制**只对 LVCMOS 模式**, 原文明写"LVDS 电平模式不涉及")
- 🔴 **`VCCIO_202` 不存在** —— bank202(DDR 地址/命令)没有自己的供电球, 由 `VCCIO_203` 一起供
  ⇒ **电源树上 DDR 只有一路 VDDQ**, 覆盖 202+203 共 75 根脚
- **`HSWAPEN` = 球 K16**(`IO_R3P_32`), 两份表一致

## 其他会咬人的手册事实

- 🔴 **表 2-6: bank33 有 35 个球上电状态被硬性固定, HSWAPEN 管不了** ⇒ 单独成篇,
  见 [[reference_dr1_bank33_poweron_forced_pins]]。**这是本次最值钱的发现**,
  它直接推翻"上行 14 対沿用 bank33"这个默认值。
- 🔴 **LVDS25 作接收时必须外部 100Ω 端接或打开片内 100Ω, 否则可能损坏器件**(UG1210 §2.6.3);
  **LVDS18 无此限制**。⇒ 板上留 100Ω 位, 默认不贴, 先用片内(实测范围 65~135Ω)。
- **上电顺序 `VCCINT` → `VCCAUX`(VCCPLL) → `VCCIO`**, 下电反序;
  每路 GND→90% 必须落在 **0.2~100ms** 窗口内(**太快也不合规**)。
- **上电到 DONE 最坏 ~90ms**(`TPOR`≤49.2 + `TPROG`≤39.6 + `TCCLK`≈5µs) ⇒ 看门狗超时要 >100ms。
- 🔴 **不用 ADC 也必须接**: `VCCADC`(磁珠接 VCCAUX)/`GNDADC`/`VREFN`(必须接 GNDADC)
  **一律不许悬空或接地**(DS1200 表 4-2)。
- **单端 I/O 一律 300Mbps 封顶**, 只有 LVDS25/18 能到 1250 ⇒ 任何 >300Mbps 必须走真差分,
  也就**必须把那个 bank 的 VCCIO 设成 2.5 或 1.8V**。3.3V bank 只能走 300Mbps 的模拟 LVDS + 3R 网络。
- **必须的上下拉**: TCK/PROGRAMN/DONE/INITN 各 4.7kΩ 上拉 · `RSV_R2GND`(**F8 和 G10 两个球**)
  4.7kΩ 下拉(**G10=0 才允许 PS BOOT**) · `RSV_NC`(T13) 4.7kΩ 上拉 · `PS_DDR_RSTN` 4.7kΩ 下拉。
- **Boot strap `PS_IO[8:2]` 真值表**在 UG1214 §2.3 + §9.1.2(表 2-2/2-3/2-4/9-1):
  `[5:3]`=启动模式(000=JTAG / 100=QSPI24 / 110=SD / 101=QSPI32 / 001=eMMC …) ·
  `[7]/[8]`=bank200/201 电压模式(0,0=2.5/3.3V; 1,1=1.8V, **必须和电源树实际给的一致**) ·
  `[6]`=PLL(0=EN) · `[2]`=JTAG 链(1=no-daisy)。
  🔴 **strap 与 QSPI 共脚**(UG1214: "QSPI 启动的管脚位置为 PS_IO_1–PS_IO_6")⇒ 必须弱上下拉。
  🔴 **boot mode 做成可切, 别焊死**。
- **`PS_CLK` 25~50MHz**(FS03 用 33.33M), duty 40~60%, 上升沿 ≤6ns; PL 时钟 FS03 用 25M。
- **DDR3L 1.35V 有手册出入**: UG1214 表 2-1 写支持 1.2/1.35/1.5V, 而 DS1200 表 3-4
  **只列了 1.5V 和 1.2V 两档**。FS03 实机跑 1.35V ⇒ 可用, 但**写进评审前要书面确认**。

## 🔴 待向安路索取(P0 三条)

   ⇒ 在拿到之前只能照抄 FS03 原理图。

   (对照: Zynq 那块板是从 Vivado 的 IBIS `.pkg` 自动提取 484 球映射的。)
3. **IBIS 模型** —— 要跑 1250Mbps LVDS, 没模型只能靠实测。

P1: **UG1210 是 0.1 草稿版**(2024.01, 带米联客水印), **而它正是讲 LVDS 端接和共模的那本** ——
整块板的核心风险就在这里, 正式版优先要。另: UG12xx 缺 1203/1205/1207/1208/1209/1211/1213,
