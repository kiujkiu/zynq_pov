## ✅ 对插修好了
灯板 CN3↔转接板 CN2 (74) + 灯板 CN4↔转接板 CN1 (50) = **124 信号脚 0 处不符**, 电源/地位置无信号窜入。换算规则不变。

**FPGA 球位一个没动** ⇒ 只改连接器脚位不影响球位这条得到验证, 09-16 的 .cst 在球位层面仍有效。

## 🔴 转接板新引入(我逐项复核过)
1. **2V8 实际 3.73V**: U6(STI3411A, Vref 0.6V) → **U9 TPS54560DDAR-JSM(Vref 0.8V, TI SLVSC60 表 0.792/0.8/0.808)**, 但反馈 R161 110k / R162 30k 照抄没改 ⇒ 0.8×(1+110/30)=3.73V。改 R161→**75k**(或 R162→44.2k)。
   ⚠ 后果要说准: 2260 VDDR 规格 2.8~4.2V(绝对最大 5V), **不会击穿**; 代价是每颗红色恒流源多掉 0.93V×0.384A≈0.36W, 12 颗多耗 **4.3W** 全在芯片里; 另需核灯板 2.8V 轨上 8 只 220µF 的耐压。
2. **缺续流二极管**: TPS54560 是非同步 buck, TI §8.2.2.5 原文要求 SW→GND 外接; 全图零个二极管位号(SW 上只有 BOOT 电容和 L4)。补 ≥5A/40V 肖特基。
   顺带: L4 封装标注在新版消失(旧版 SWPA4018S 4×4mm), 2.2µH 带 5A 大概率饱和。

## 🔴 灯板新增
- **位号全重编**: U1–U12→**U19–U30**、CN1/CN2→**CN3/CN4**、RA3–RL3→**RA1–RL1**、C1–C124→C125 起、铜柱→U31–U36; **标题栏整块被删**。
- **LVDS_EN 12 只上拉丢了阻值**(旧 4.7kΩ, 新版无值, 部分显示库名 `Res3`) ⇒ BOM 漏料。
- **PCB(03:32) 比原理图(18:48) 旧**: SYNC1 那根还没改到 PCB。
- 芯片侧逐脚核过与 09-16 一模一样(SCL/SDA 悬空、ACK 无上拉、DCLK 悬空、VDDD 3.8V、无电源入口、无共模逃生位)。
- ACK↔链号错位依旧(新位号): U23=链6/5ACK · U24=链7/6ACK · U25=链8/7ACK · U26=链4/8ACK · U27=链5/9ACK。
