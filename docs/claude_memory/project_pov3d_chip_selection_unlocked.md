# 两级选型都不锁定 (2026-09-10 用户澄清)

**用户原话**: 「主 soc 和桥 soc 都不要锁定, 主 soc 目前主要是 7020 和安路 dr1v90, 桥有很多备选, 安路和高云都有」。
⇒ 推翻此前把 **EG4A20BG256I7(09-07)** 与 **DR1V90GEG484** 当「已定」的口径。
📄 排期文档: `zynq_pov/docs/硬件工作拆解_2026-09-09.html` §1。

## 为什么不锁定并不阻塞画板 —— 两层解耦已经做好了

| 层 | 解耦方式 | 性质 |
|---|---|---|
| **主控** | XC7Z020-CLG484 与 DR1V90GEG484 **484 球 pin2pin** | 几何巧合(见 [[reference_anlogic_dr1_fs03_eval]]) |
| **桥片** | 灯板邮票孔接口冻结, 「灯板是常量, FPGA 子板是变量」 | 主动设计(见 [[project_pov3d_panel_rework_stamp_interface]]) |

🎯 **主控可以画成一块双兼容板**。物理差异只有四处, 全在电源与 strap:
VCCINT **1.0 → 0.95 V**(且 Zynq 的 VCCINT/VCCBRAM/VCCPINT 三轨在 DR1 合并成一条) ·
VCCAUX 与 VCCPAUX 合并 · CFGBVS(T13) → RSV_NC · VCCBATT/RSVDVCC1-3/DXP/DXN → NC。
⇒ 代价 = VCCINT 轨做成 0.95/1.0 可选 + 几个 strap 留跳线, **是额外工作不是额外周期**。

🎯 **桥片换片灯板一个字不用改**, 连「12 対时钟从哪来」(子板扇出 IC vs FPGA 直出)都吸收在子板侧。
且同一块转接板能插 EG4 与 GW5A 两种核心板(见 [[project_pov3d_adapter_board_and_uplink_bank]])。

## 三条所有候选共同的约束 —— 换片解决不了

1. **目标板 24 颗只能走 B/D 时钟拓扑**。A 方案(每颗一対独立时钟)要 238 pad,
   **所有 GW5A 封装都撑不住**, 只有 GW5AT-60 PG484A 有可能而它同样买不到;
   现役 EG4A20 的 196 IO 本来也撑不住 ⇒ **这条与选型无关**。
2. **VOCM 超窗是全行业问题**。所有候选 VOCM max 都在 1.375~1.425 V, 超出 2260 的 1.3 V。
   EG4 的 3R/5R 网络反而能把共模**按构造**钉在 1.20 V ⇒ 灯板那 60 个 0402 逃生位**对每种候选都要留**。
3. **供货才是真正的杀手, 不是参数** ⇒ 选型的收敛点在**询价单的货期列**, 不在参数表。

## 收敛线: 三个点收口, 不是一个前置门

| 收口点 | 从 → 到 | 靠什么 |
|---|---|---|
| M0 结束 | 参数够的 → **买得到的** | 询价单货期与价格列 |
| M2 结束 | 买得到的 → **实测能用的** | 验证板三条硬轴(共模/gearing/时序) |
| M3 开始 | 定版 | 上面两条的交集 |

## 代价落在验证板灯板上

🔴 **邮票孔一旦焊上, 那块灯板就绑定那块子板**。要试两种子板 ⇒ 要么做两块灯板,
要么**焊盘按邮票孔画的同时兼容一个板对板连接器封装**(验证期插连接器、定版后直焊)。
**建议后者** —— 多花几十个焊盘面积, 省一整块灯板的打样费与约三周。

## ⚠ 2026-09-11 门槛更正

⚠ **2026-09-11 更正**: 原先按「用 8b/10b ⇒ ×1.25 ⇒ 12-bit@700M 要 29 対」估,
实测 RTL 用的是**源同步 + 帧头对 (0x35,0xCA) 每 128 字一次 ⇒ ×1.0156 ⇒ 只要 24 対**。
⇒ **12-bit 的真实门槛 = 73 + 24 = 97 対, 不是 102**(见 [[project_pov3d_uplink_rate_pin_budget]] 结案节)。
按 97 対重筛: EG4A20(86)❌ · **PH1A60(100)✅余3**(被救活) · GW5A-60(110)✅余13 ·
GW5A-25(116 标称/最坏 85⚠) · **PGL22G(120)✅余23, 且対数逐球数过、生态最成熟**。
🔴 目标板要贴**散片**, 而 GW5A 全系散片受限供货、紫光裸片渠道也未确认 —— **这才是目标板的真风险, 不是対数**。
