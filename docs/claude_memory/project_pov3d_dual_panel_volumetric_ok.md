**2026-07-28: 从 PC 渲染到双屏立体成像, 整条链第一次端到端验证通过。**

```
GLB → 体素化 → 偏移平面切片(gap 13.8mm) → 中心轴镜像 → 1-bit Bayer → pack_obs
    → [WiFi 推流 或 pscp+直写DDR] → DDR → FPGA 按角度取片 → 双屏 ICND2047
    → 电机 11.1 rps → ✅ 体显示正确
```

## 正确配置 (照抄即可)

| 项 | 值 |
|---|---|
| 引脚映射 | 转接板 v1.2 新序, 见 [[project_pov3d_trans_v12_pinmap]] |
| 切片几何 | `--gap-mm 13.8` 偏移平面, 见 [[project_pov3d_offset_axis_geometry]] |
| 手性 | host `--mirror-u` **ON** (默认), 全局中心轴翻转 |
| 屏B 额外镜像 | RTL `mirror_b` = **0** (0x10[4]) — **两屏吃同一次 host 镜像** |
| POV 控制 | `0x10 = (360<<16)|0x5` = pov_en + dual_en |
| 引擎 cfg | `0x0C`: `0x000001FF` → `0x9836C001`(54行/oe192) → `0xC1000003`(auto+use_fb) |
| 亮度 | oe_window 192 → 引擎内箝 187, 占空 95.9% (已到顶) |

## 实测基线

- `rev_period` 4504827 拍 @50MHz = **90.1 ms/圈 = 11.10 rps = 666 RPM**
- 每屏 3996 片/s, 双屏 7992 片/s (13rps 预算是 9360, 当前余量更宽)
- `PHASE_B=180` 验证: idx=155 时 idx_B=335 ✅
- WiFi 推流: 144 帧动画 **9.89 fps, 压缩 35.9×, 链路占用 36%**, 见 [[reference_pov_wifi_streaming]]

## 🔴 判断体显示只能在转动时进行

静止时屏A=slice i、屏B=slice i+180 **本就是两个不同平面**, 在两个不同截面之间比较
得不出任何关于镜像/手性的结论。2026-07-28 在这上面反复了很多次, 直到电机转起来才定案。

⚠ 未决: 屏 B 的 **G3 不亮** (P3.21 → 接口板 R30 10Ω 串阻最可疑, 一直没量)。
该链路旧序里是屏2 行驱 RCLK、从没通过电, 所以到双屏才第一次暴露。
