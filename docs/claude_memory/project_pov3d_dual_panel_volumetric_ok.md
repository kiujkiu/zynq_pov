## 🔴 判断体显示只能在转动时进行

静止时屏A=slice i、屏B=slice i+180 **本就是两个不同平面**, 在两个不同截面之间比较
得不出任何关于镜像/手性的结论。2026-07-28 在这上面反复了很多次, 直到电机转起来才定案。

## ✅ 已解决: 屏 B 的 G3 不亮 (2026-07-28)

症状: 换 v1.2 转接板 + 双屏后, 屏 B 的 G3 (绿, 区3) 单独一路不亮, 其余正常。
定位: `FPGA T4 ── J12.29 ── 接口板 P2.29 ──[R30 10Ω]── P3.21 ── 转接板 ── J1.11 ── 屏 G3IN`
根因在**接口板 R30** (10Ω 串阻), 用户修复后**实测确认恢复正常**。

🔴 **为什么到今天才暴露**: 旧引脚序里 P3.21 是屏2 的**行驱 RCLK**, 而此前一直单屏跑,
屏2 整组从没通过电 → R30 漏贴/虚焊多年无人发现。**换线序 + 上双屏 = 第一次点亮这条链路**,
所以它看起来像"新引脚序的锅", 其实跟映射无关。

排查时的关键判断: 先用差分对结构性校验确认 `T4=IO_L20P_T3_13` 配 `U4=IO_L20N_T3_13`
(19 对 CEP2 全中), 排除"屏2 ball 表写错"; 只死一路而非整片错乱, 也指向物理断线而非映射错。
**教训**: 单根信号不通优先查物理链路 (串阻/焊点/线缆), 别先怀疑映射表。
