# E104 开发板 ↔ ICND2260 灯板 验证方案 (2026-09-04 定)

**文档**: `zynq_pov/docs/E104_2260_接线方案.md` (284 行, 含完整 14 行接线表)
**资料**: `D:\BaiduNetdiskDownload\ANLOGIC EAGLE FPGA E104发布文档_V1.0\`

## 为什么买这块板

器件 **EG4X20BG256** —— 与目标 EG4A20BG256 同族同封装, **X/A 型无内嵌 SDRAM ⇒ bank 电压自由**
(若是 S20 则 bank1/3 锁 3.3V, 验不了)。比自己画验证板早 6 周。

## 🔴 bank 电压: 只有 bank1 可调

【用户手册 §3.5】VCCIO0/2/3 **固定 3.3V**; **VCCIO1 可调** —— **拆 R23 焊 R22** 即为 2.5V。
电路是两只 0Ω 二选一(`+2.5V─[R22 0R/NC]─┬─VCCIO`, `+3.3V─[R23 0R]─┘`)。
板上 +2.5V 来自 AMS1117(2.5V/1A), 本就是给 FPGA IO 准备的。
⚠ **bank0/2 不要动** —— VCCIO 是 BGA 球下打孔直连内层平面**割不到**;
且 bank0 挂 SDRAM+HSWAPEN, bank2 挂 CCLK/MSEL0 配置脚。
(VCCIO0 只有 1 个球 B13, VCCIO2 有 4 个 N7/N10/R4/R8 —— 球少也没用, 平面改不了)

## 🎯 5R 电阻网络: 用 3.3V bank 也能驱屏

仿真 LVDS 是 **CMOS 驱动 + 电阻网络**, 共模天然 = **VCCIO/2**:
- VCCIO 2.5V → **1.25V** ✅ 在 2260 的 `VIC` 1.1~1.3 内 (**最终板就是这样**)
- VCCIO 3.3V → **1.65V** 🔴 出窗

⇒ E104 上每腿加一只对地电阻 `Rpd` 把共模拉下来:
```
VCM = (VCCIO/2) × Rpd / (Rpd + Rout + RS)      Rout = 10Ω 【TN309 注1】
```

| 参数 | 值 | 结果 |
|---|---|---|
| `RS` / `RP` | **150 / 140 Ω** | UG303 表3-1 / TN309 表4-2 的 150/140 档 |
| **`Rpd`** | **430 Ω** (E24) | |
| ⇒ 共模 | **1.203 V** | ✅ 2260 窗口正中 |
| ⇒ 幅值 | **432 mV** | ✅ `VID` ±100~±600 内, > `VTH` 100mV, < 500mV 门槛可用片内端接 |
| 差分衰减 | 10.5% | 两只 Rpd 串联 860Ω 跨接, 与 100Ω 并联 → 89.5Ω |

🔴 **RS 与 Rpd 必须配对**: 同样 430Ω 配 RS=210 共模掉到 1.092V **出窗**。
其它档: 300/118→Rpd 827(241mV) · 210/127→587(327mV) · 115/160→333(530mV, >500 要片外端接)

## 引脚分配 (从 `E104分组约束表.xlsx` 的 `PPr` 行逐条挑出)

| 2260 | E104 J4 | FPGA 球 | 类型 |
|---|---|---|---|
| `clk_p/n` | **J4.16 / J4.15** | J13 / K14 (`GCLKIOL5/4`) | 真差分 bank1, `VCM=1.2` |
| `b_p/n` (D0) | **J4.58 / J4.57** | B12 / A12 (`BE16`) | 仿真 +5R |
| `g_p/n` (D1) | **J4.56 / J4.55** | C13 / A13 (`BE17`) | 仿真 +5R |
| `r_p/n` (D2) | **J4.54 / J4.53** | B14 / A14 (`BE19`) | 仿真 +5R |
| `sync`/`ack`/`dclk` | J4.50 / 49 / 48 | B15 / B16 / C15 | LVCMOS25 bank1 |
| GND | J4.1-2, 19-20, 41-42, 59-60 | — | |

⚠ **极性**: J4.**16**=L14**P**=`clk_p`, J4.**15**=L14**N**。**排针奇偶与 P/N 不对应。**
⚠ 三个数据対在排针上**连号相邻**(J4.53~58), 飞线最短。
⚠ **E104 的 J4 不供 2260 的电** —— VDDR 2.8V / VDDGB 3.8V 外接, 与 E104 共地。

### 🎯 比原先数的多两対仿真対
除 `BE16`/`BE17`, **J4.51~54 还有 `BE20`(D12/D11) 与 `BE19`(A14/B14)**
⇒ **bank0 在 J4 上有 4 対连续仿真対(J4.51~58)**, 加 bank2 的 `TE8`(J4.3/4)、`TE13`(J3.13/14)
= **共 6 対可用**。⇒ **用 J4.51~58 四対可全仿真対驱一颗 2260, 完全不碰 bank1**,
能做"时钟真差分 vs 时钟也仿真"两组对照。
⚠ `BE19`/`BE20` 复用 `GPLL0_CLKIN`/`GPLL0_OUT`, 综合时确认 PLL0 未被占用; 冲突则 D2 退回 `TE8`。

### J4 全貌 (56 脚有约束, 板厂按差分対等长, 失配 <5 mil)
J4.1-2/19-20/41-42/59-60 = GND · J4.3-4 = `TE8`(bank2) ·
J4.5-50 = bank1 真差分 21 対(含 J4.15-18 两対 GCLKIOL) · J4.51-58 = bank0 仿真 4 対

## 四个实验 (按价值)

| # | 实验 | 判据 |
|---|---|---|
| ④ ★ | **仿真対 5R 驱 2260 @166 MHz** | 屏亮 + ACK 回包 —— **最终屏板 73 対下行里 51 対是仿真対, 这条纸面零背书** |
| ② | 真差分驱 2260 @332 Mbps | 屏亮 + ACK(建立基准, 先做) |
| ① | 量 VCM 三档实际共模 | 设 0.8/0.9/1.2 各量一次 |
| ③ | 800M 上行环回 + 眼图 | PRBS 误码率 |

**④ 测到**: CMOS+电阻网络能否 166MHz 驱 2260、电阻网络 SI、2260 认不认这种非标准 LVDS
**④ 没测到**: LVDS25E 在 2.5V 下的原生行为、3R(而非 5R)的实际衰减
⇒ 最终板换 LVDS25E+3R 只是**把 Rpd 拿掉、共模由 VCCIO/2 天然给定**, 是**更简单**的配置。

⚠ `LVDS33_E` 工具接受到 bit, 但 **DS300 表 3-2-5 输出频率表只有 LVDS25E**;
TN309 表4-2 与 UG303 表3-1 给了 LVDSE33 幅值列 ⇒ **存在但无频率背书, 166MHz 能否跑正是要测的**。

## 🔴 三条踩过的坑 (接线前必看)
1. **第一通道是 D0 = SDI_B1(B 対), 不是 R** —— TTL 走 SDI_R1 但 mLVDS 一律走 D0
2. **灯板脚位图是列优先**(左 1~20, 右 21~40), 读成行优先全错
3. **电源两路曾接反** —— J1.1-5 要 **2.8V**(VDDR), J1.16-20 要 **3.8V**(VDDGB);
   VDDGB < 3.5V ⇒ 绿蓝不亮。**接线前先用万用表量**
4. **每対差分自己带一根地** —— 时钟対 J4.15/16 离最近地脚(J4.19/20)隔 3 脚;
   踩过「J1.21/22 紧邻无地 ⇒ DCLK 串扰拽出 5 万假帧」

## 源同步时序 (照搬现役, 别改)
mini-LVDS `tSTU/tHLD` = **1/4 tLVCP**【DS V1.7】⇒ 芯片在**位中间**采样
⇒ **转发时钟必须比数据晚 90°**。Xilinx 用 MMCM `CLKOUT1_PHASE=90`;
EG4 用 `CLKCx_FPHASE = 4`(4 × 22.5° = 90°, 合法范围 [0,7], 实测可验证生效)。
🔴 **与 TTL 版的"边沿对齐"要求正好相反, 别混用两份约束。**

## 灯板参数 (供应商客户样板, 拿不到原理图)
9 颗级联 · 每颗 40px × 45 扫 · **板上无端接**(100Ω 要自己加在灯板侧) ·
连接器上**无 RSTN**(板内自处理) · 2260 只有 I2C 的 SCL/SDA
