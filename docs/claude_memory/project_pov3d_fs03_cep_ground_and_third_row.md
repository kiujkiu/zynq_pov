# FS03 CEP 连接器与"加第三排地针"的论证 (2026-09-04 会话, 09-07 并入)

🔴 **本文正文写于 09-04, 当时桥片还按 EG4S20CG324 论证; 09-07 选型已收敛到 EG4A20BG256I7**
(见 [[project_pov3d_eg4a20bg256_bridge_selection]])。受影响的只有 §3 那条, 已就地标注。

## §1 CEP 引脚表: 只有 2 根地, 且排针列 = 真差分対

【手册原文】`米联客-MLKPAI_FS03_DR1开发平台硬件使用手册.pdf` §16 GPIO
(`pdftotext -layout` 可直接取完整表; §1 规格栏写 "两组 GPIO 共 96/48 对差分"):

```
CEP1 / CEP2 各 50 脚 = 1 VCC + 1 GND(pin 2) + 48 个 FPGA IO
⇒ 合计 96 信号 : 2 根地, 且那 2 根在连接器最边上, 离远端信号 24 列远
```

🎯 **结掉了 [[reference_fs03_cep_connector_pinout]] 里"(n,n+1) 只是排针物理列, 不等于差分対"那条待查**
—— 逐脚回查 `DR1M90_DR1V90GEG484_PINLIST` 后确认**就是**差分対:

| | 归属 | 対数 |
|---|---|---|
| **CEP1** | DR1 **Bank 33** 全部 24 対 (`IO_R1..R24_33`) | 24 |
| **CEP2** | DR1 **Bank 11** 全部 24 対 (`IO_L1..L24_11`) | 24(见 §2) |

**奇数脚恒 P, 偶数脚恒 N, 跨列 0 対、孤儿 0 対**, 无一例外。
佐证: `dr1v90/uplink_tx/soc_prj/uisrc/04_pin/uplink_pin.adc` 那 14 対 800Mbps 探针球位
(G15/F16/D16/E15/F18/G17/C15/B16/A16/A18/A21/D22/H19/F21) **100% 落在 CEP1**,
即 09-03 那个 `SWNS +0.010 / DDRX2 14/14` 的结论**天然就是 CEP1 的结论**。
⚠ 其中 8 対注了"复用 ADC" —— 板级有无附加网络未查。

## §2 🔴 手册 CEP2 pin7 写的 Y19 是笔误

`Y19 = IO_R11P_31` 属 **Bank 31**(MIPI 那组), 与 pin8 的 `Y8 = IO_L12N_11` **跨 bank, 不成対**。
而 Bank 11 的 48 个 IO 里**恰好只有 `Y9 = IO_L12P_11` 没出现在 CEP2 表里** ⇒ 强烈指向 pin7 应为 Y9。

⚠ 三种互斥读法, 文档判不了: ① pin7 应为 Y9 ② pin8 应为 AA19(则 CEP2 跨 bank, 破坏"一连接器一 VCCIO")
③ Y19 真的与 MIPI pin18 共球 ⇒ CEP2.7 上挂一段通往 MIPI 座的**残桩**, 对 800 Mbps 致命且看不出来。
🔴 **而这一対正好是 GCLK 対** —— 你会拿来放随路时钟的那対。
✅ **2026-09-15 原理图坐实读法①**: FS03 原理图 p17 J12 pin7 = CEP2_3P → R200(33Ω) → BK11_L12P → **Y9**, pin8 = CEP2_3N = Y8(同一 GCLK 対); 手册 Y19 是笔误, 残桩读法③排除。仍待 toggle 位流确认才作转发时钟。
**判法(原文留档)**: 万用表只能做 CEP2.7↔MIPI pin18 同网旁证(两球都在 484 球 BGA 底下, 且 MIPI 有电阻网络,
不响不能证伪); 定论要 RTL 侧烧一个 toggle 位流看 CEP2.7 动不动。**没打通之前这一列不得做 forwarded clock。**

## §3 🔴 FS03 无 2.5V 轨 ⇒ 只能 LVDS18, 而 LVDS18 的共模擦边

【手册原文】FS03 §18 电源: 只有 **3.3V / 1.8V / 1.35V**, 全文检索 "2.5" 零命中。
⇒ DR1 只能发 **LVDS18**。这点 `uplink_pin.adc` 注释里**早就写死了**("FS03 无 2.5V 轨 ⇒ LVDS25 不可实现;
LVDS18 与 LVDS25 同为 1250 Mbps, 需把 **J2(ADJ_BANK33) 跳到 1.8V 侧**"), 不是新问题。

**新问题在收端**:

| | 共模窗口 | 来源 |
|---|---|---|
| DR1 **LVDS18 输出** VOCM | 0.3 / **0.6** / 0.8 V | 【手册原文】DS1200 表 3-14 |
| DR1 LVDS25 输出 VOCM (对照) | 0.9 / 1.25 / 1.4 V | 同上 |
| EG4 **输入** VICM @ VCCIO=**3.3V** | **0.6** ~ 3.15 V | 【手册原文】DS300 表 3-1-15 |
| EG4 **输入** VICM @ VCCIO=**2.5V** | **0.05 ~ 2.35 V** | 同上 |

⇒ **上行 RX 若落在 VCCIO=3.3V 的 bank 上, 典型值正好压在窗口下沿, 最小值出窗 300 mV。**

**对 EG4S20CG324**(09-04 当时的候选): Bank1/3 那 50 対真差分被内嵌 SDRAM 电源短接**锁死 3.3V**
⇒ 上行 RX 必须放 Bank0/2 的**仿真対 @2.5V**, 代价是仿真対无片内 100Ω, 端接要外挂一只。
🔴 这**推翻了** [[reference_eg4s20_bank_voltage_and_lvds33]] 09-04 的结论
("Bank1/3 锁 3.3V 不构成障碍, RX 放 Bank1/3 完全没问题") —— 那条是按 **LVDS25(VOCM 1.25)** 算的,
对最终自制主控板成立, **对 FS03 过渡台不成立**。

✅ **对 09-07 选定的 EG4A20BG256I7: 这条自动解掉** —— A20 **无内嵌 SDRAM ⇒ Bank1/3 可配 2.5V**
⇒ VICM 0.05~2.35 完整包住 LVDS18 的 0.3~0.8, 且真対**有**片内 100Ω, 不用外挂端接。
⚠ **待确认**: A20 上行 RX 那几个 bank 是否真的配成 2.5V(09-07 只写了下行 `VCM=1.2 直连 2260`,
那是 **EG4→2260** 段, 与本条的 **DR1→EG4** 段是两回事, 别混)。

## §4 "加第三排地针"的论证 (用户 09-04 提出)

原提法: FS03 是 2×25 双排针, 加一排全焊通的地针做成三排。

**买到的(成立)**
- 地/信号 **2:96 → 约 50:96**, 且**不牺牲任何一対信号** —— 唯一零対数代价的配地办法
- 共模回流从"横跨 63mm 板边回到 pin2"缩到就近 2.54mm。**这正是鹿小班 5 万假帧的机制**
  (共阻抗/回流, 不是遮挡), 共享回流电感降约 6~16×

**买不到的三条**
1. 🔴 **対与対之间的屏蔽**。既然排针列就是 P/N 対(§1), 第三排只能贴在 N 排外侧,
   **永远插不进相邻两対之间**; 而 2.54mm 方栅格上**対内间距 = 対间间距**(耦合系数都约 0.34)。
   要真插进列间只能牺牲信号列: 24 対 → 12~16 対。
2. **対数**: 12-bit@700M 要 49 列 > 48 列 —— 与地无关, 第三排一根信号脚都不增加。
3. **不对称**: 单侧一排地 ⇒ N 到地 2.54mm 而 P 到地 5.08mm, 引入**差模↔共模转换**。

**要改的三处**
1. **两侧各加一排, 做 G-P-N-G 四排** —— 不是"同一件事做两遍", 是消掉第 3 条不对称。
2. 🔴 **地条必须沿长度 ≥3 点接回 FS03 真地**(最关键)。25 针 × 2.54 = 63.5mm 的地条若只从 pin2
   一点接回, 自身约 50 nH、**λ/4 谐振落在 0.96~1.18 GHz**, 正压在 800 Mbps 边沿频谱里,
   从"地"变成**带内谐振器**, 净改善约 **9% ≈ 零**。
   判据: 最长自由段 **≤21mm**, 每个接点 **≤5mm**(30AWG 走 10mm 就有 8.6 nH, 比它要救的针还差)。
3. **地排做在转接板那一侧, FS03 侧只焊几根短线** —— 成品板上贴着现有排针焊 25 针机械对位难,
   且**一个虚焊的地针比没有更糟**(变成开路残桩)。

## §5 两条口径修正 + 一条幻觉

- 🔴 **">=1 根地/対"这条"硬要求"的实测背书来自 25 MHz 单端 LVCMOS**(鹿小班 DCLK 打 ACK,
  见 [[project_lxb_icnd2260_bringup]]), 对 350mV 摆幅、P/N 同列、收端 ±100mV 差分门限的 LVDS
  **不能直接外推**。在补一次差分口径实测之前, 应降格为**工程惯例**而非硬判据。
- **[[project_pov3d_uplink_rate_pin_budget]] 缺口二的数要改口径**: 原表写 800M 1.21 / 700M 0.81
  "根地/対", 那是**从 96 根 IO 里匀的伪地**; 专用地只有 2 根 ⇒ 同口径真值
  800M **2/28=0.07** / 700M **2/32=0.063**。
  实质变化只有 **800M 由"过"翻为"不过"这一个布尔翻转**, 别用"低估 39 倍"这种表述(串了量纲)。
- ~~🔴 **幻觉记录**: 有 agent 报"手册 2D 图显示 CEP1 正下方有 R188~R196 九个四合一排阻(36 只),
  若是串阻则 LVDS 全盘作废"。**手册全文 grep 零命中** —— 那是图片, pdftotext 读不到, **判为编造, 已丢弃**。~~
  🔴🔴 **2026-09-15 翻案: 串阻是真的** —— FS03 原理图 P17_GPIO 与 BOM: **R187~R210 = 33R RA4_0402 ×24, 96 根 CEP 线每根一只**
  (链路 CEP 脚 → 33Ω → BK33/BK11 球)。当年"grep 零命中 ⇒ 编造"是**拿读不到图的工具去否定图里的东西**(与 [[reference_lxb_gpio1_pinout]] 同一类错)。
  "LVDS 全盘作废"仍是夸大: 33Ω/腿对 800 Mbps LVDS 的实际影响(幅值、阻抗不连续)待评估, 可考虑换 0Ω。见 [[project_pov3d_hw_pack_dr1v90_gw5a]]。
  但它给的判法本身对且便宜, 值得当例行确认: 把某脚配成 LVCMOS33 16mA 输出高,
  排针脚挂 100Ω 到地量电压 —— **无串阻 ≈3.2V, 33Ω 串阻 ≈2.4V**(15 分钟)。

## 🔴 2026-09-07 追加: CEP1 = Bank33, 而 Bank33 的上电状态是被硬性固定的

本篇查明「**CEP1 = DR1 Bank33 全 24 対 `IO_R1..R24_33`**」, 09-07 整理自研板资料时挖到
**DS1200 §2.8.2 表 2-6**: bank33 有 **35 个球在上电完成到程序加载完成前(最坏 ~90ms)
状态被硬性固定, `HSWAPEN` 管不了** —— 其中 **4 対差分被劈开**
(`R16_33` 是 **P 端下拉 GND / N 端上拉 VCCIO**)。

⇒ **CEP1 上那 24 対(含 09-03 那 14 対 800M 探针)在上电后 90ms 内, 对端看到的不是"无信号",
而是一个稳定的假差分电平** —— 这一点我们从来没有考虑过。
⚠ 不解释任何已知故障(上行是我们自己收, 不是屏在收), 但**接屏时要重新想一遍**。
完整球位表与判据见 [[reference_dr1_bank33_poweron_forced_pins]]。
