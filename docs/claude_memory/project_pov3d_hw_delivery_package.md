## ✅ rev.4 已定稿并写入 zip (09-11): 两版本硬件 → 小目标 → 交付物
用户原意: 硬件任务其实就是**两个版本的硬件**, 拆"先验证板再目标板"是为了**帮硬件同事熟悉环境 + 尽快有的用**; 每个版本再拆 **2~4 个小目标**, 要求**有明确交付物、能直接支撑版本目标、最有价值最有效**。三层: 版本 → 小目标 → 交付物(现有 V1~V3 / T1~T2 / S1~S5 内容不变, 只重新挂)。

定稿结构(**已写进 03 / 06 / 读我.txt, `POV3D_硬件交付包_2026-09-11.zip` 208KB 已重打, 现为 rev.4(含支撑关系)**):
- **版本一 验证板**(V1+V2+V3) 目标 = 尽快拿到能用的台架, 用它测掉目标板最大风险
  - **1-1 开画前定案**: 桥片选型报告(型号+自研/核心板+采购价格货期, S1) + ICD v1 含速率结论(S3)
  - **1-2 三块板回板并点亮**: 12 颗 2260 点亮 + ACK 回包 ⇒ 交软件侧调固件
  - **1-3 三条硬轴测试报告**: 共模/眼图 + 上行环回两档误码 + 相位, 附**给目标板的设计输入清单**(端接/线速率/対数) ⇒ **版本二唯一硬门槛**
- **版本二 目标板**(T1×2 + T2) 目标 = 双面点亮 + 上转子达标(900 RPM · 30 Hz · 48 W)。🔄 **用户 09-11 追加: "目标板因为需要重做内容较多, 再打一层"** ⇒ 版本二按板分线, 每线再拆小目标(取代先前的 2-1/2-2/2-3 三段):
  - **2A LED 板线(T1)**: 2A-1 定案 = 屏体路线(S5, COB 打样 3 个月) + 亮度结论(S4) → 定电流/功耗/屏体形式, 🔴 版本一期间并行 · 2A-2 设计投产 = 原理图 + 8 层 HDI + SI 仿真 + 投产 · **2A-3 单板点亮 = 接验证版 SOC 侧(FS03+V3)驱动**, 全阵列无坏区
  - **2B SOC 板线(T2)**: 2B-1 定案 = 主 SOC 选型+采购(S2) + 板级需求(2.5V 轨/DDR/接口対数按 S3), 🔴 版本一期间并行 · 2B-2 设计投产 = 参考 FS03 硬件包 / DR1V90 交接包 · **2B-3 单板 bring-up = 上电时序/启动/DDR 通过 + 接验证版 LED 侧(V1+V2)跑通误码 0**
