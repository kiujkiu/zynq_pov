# 新硬件同事 3 个月试用期任务 (2026-09-04)

排法原则: **先量后选、先小板后大板**, 每周有可验收交付物。
前提: **桥片选型还没定**(GW5A-60 / PH1A60 / EG4S20 三选一, 价格货期全空白) ⇒ 屏板不能第一周开画。

## 阶段一 W1–4: 摸底与定案(不画板, 把未知数量出来)

| 周 | 任务 | 交付判据 |
|---|---|---|
| W1 | 环境 + 现状摸底, 建板间关系图 | **FS03 CEP1+CEP2 完整引脚表: 96 根信号外有无专用 GND 脚、几根** —— 卡了很久, 直接决定上行速率档 |
| W2 | 屏侧电气实测(鹿小班板 + 2260 样板) | 🔴 ~~① 量 ICND1069 的 REXT~~ **整条作废**(用户 09-04 口头定: **ICND1069 已从计划去掉, 只做 2260**) ② 2260 电流/温升/**实测共模** ⇐ W2 只剩这一项 |
| W3 | 转子供电与功率预算 | 🔴 **09-08 更新: 供电方式已明确 = 无线供电 24V 2A = 48W(现役)**; W3 改为**量实际可用功率 + 算储能电容容量 + 定亮度上限**(满白需 130 W, 只够 22%) |
| W4 | 选型收口支持(**最值钱的一周**) | 向三家问到价格+货期+技术答复 ⇒ **桥片选型定案** |

**月度评估点①**: 三个悬了很久的未知数(GND 脚 / 亮度 / 供电)有答案, 选型定案。

## 阶段二 W5–8: 小验证板(桥片 + 2~3 颗 2260)

| 周 | 任务 | 交付判据 |
|---|---|---|
| W5 | 验证板原理图 + 叠层; 与 PCB 厂确认 **0.5mm BGA225 工艺等级/HDI/价格**(2260 定死整板工艺) | 原理图评审 + 叠层(100Ω 差分) + 打样报价 |
| W6 | PCB + 打样 | 投产; 差分等长/参考平面/每对配地逐条过评审 |
| W7 | 回板 + 上电 + 配置 | 三路电源时序正确、能配置、时钟锁定 |
| W8 | **三条硬轴实测** | ① IOL 内 pclk↔sclk 相位(TD 不查) ② LVDS 驱 2260 实际共模 + 眼图 ③ 上行环回误码 |

**月度评估点②**: 小板点亮 2260, 三条硬轴有实测结论。
🔴 **这是整个试用期最关键的一块** —— 它的成败决定大板能不能画。

## 阶段三 W9–12: 全尺寸屏板

| 周 | 任务 | 交付判据 |
|---|---|---|
| W9–10 | 屏板原理图(24 颗 2260 + 桥片 + 电源 + 时钟扇出 + 终端) | 原理图 + BOM 评审; 选 EG4 还要 3R 网络 + 共模偏置 |
| W11 | PCB: LED 阵列 + 24 颗 BGA 扇出 + **73 对差分** | PCB + SI 仿真 + 评审 |
| W12 | 打样投产 + 试用期总结 | 投产、BOM 齐套、总结文档 |

## 🔴 三条要提前说清的风险

1. **W12 只到"投产", 不到"点亮"** —— 24 颗 0.5mm BGA + FPGA + ~300 只无源件的 HDI 板,
   打样+贴片+调试还要 3–4 周。**别把"大板点亮"写进考核**, 不现实。
2. **W5–8 的小板才是考核核心**。时间紧就**砍阶段三的 PCB, 也要把小板做扎实**。
3. **屏板从无源变有源是最大设计跨度**: 现役只有 2260+LED, 新板要加 FPGA、三路电源、上电时序、配置通路。
