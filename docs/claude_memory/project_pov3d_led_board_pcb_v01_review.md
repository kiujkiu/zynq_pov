# 灯板 PCB V01 审查 (2026-09-18)

原件 `C:\Users\wanqi.liu\Downloads\ICN2260_LED_V01_260918.rar`(Altium: PcbDoc 120MB + 9 张 schdoc)。
完整结论: `zynq_pov/docs/灯板PCB审查_ICN2260_LED_V01_2026-09-18.md`; **给硬件的下发件(只写结论, 含 80 脚改表)**: `zynq_pov/docs/改板结论_验证板_2026-09-18.html`; 上一份原理图审查见 [[project_pov3d_led_board_sch_0916_review]]。

## 板子
6 层(Top/Mid1-4/Bottom, 介质全是 Altium 默认 12.6mil), 163.95×225.00mm, LED 区 150×168.75mm(边距 7.9mm), 下端延长 57mm。
**LED 7200 + CN1/CN2 在 Bottom; 2260×12 + 无源 + 6 个 M2.5 铜柱在 Top**。行线 0.4mm 走 Mid3, 列线 0.1mm 走 Mid4/Bottom(这部分没问题)。

## 🔴
1. **连接器封装与松下推荐焊盘不符**: 每排 48 个 0.5mm 窄焊盘 + 2 个 0.75mm 端部焊盘(编成 1/2/99/100 并接了信号 CN1.2=CLKOP5/.99=CLKON11), 应是 50 触点@0.5mm(B=24.5mm)+另外的固定脚; 中心距 4.445 应 5.00mm; 焊盘 0.3×2.0 应 0.25×1.80。⚠ **两排不错开是对的**(松下图上的 0.25 是焊盘宽度, 我一度误读成错位)。⇒ 端部两触点偏半个节距、引脚在焊盘上偏心 0.28mm。触点编号(奇偶两排 vs 1-50/51-100)手册图未标, 要问松下。
2. **差分对跨两排**: 触点 Z 字交错编号 ⇒ 按脚号排「地-P-N-地」后, P/N 分属两排(相距 ~5mm), 同排相邻是不同对且无地。应改成同排 n/n+2 为一对。
3. **阻抗**: 实测 W=2.5mil / 中心距 5mil, 估 Zdiff≈130Ω; Altium 差分规则写 15mil/10mil 与实际不符, DifferentialPairs6 是空的。
4. 端接/共模位/上下拉一个都没加(PCB 只有 12 只 LVDS_EN 上拉电阻)。

## 🟠
- **HDI**: 无通孔; 0.07mm 孔 6.1k、0.1mm 孔 45.9k; Top→Mid2 与 Mid3→Bottom 是跨层盲孔; 54% 到底层的孔落在 LED 焊盘内(要塞孔电镀)。板价/交期必须先问板厂。
- 参考层: LVDS 全走 Top, 下方 Mid1 有 GND 铜的只占 86%。Mid4/Bottom 的 Solid 铺铜**实际没灌**。
- 49 条 DRC 间距冲突(全在 Mid3 的 CN1 扇出区); 孔到孔规则只写 0.03mm。
- 电源: 面板区铜宽够(3.8V 8.8mm/2.8V 5.1mm 内层), 瓶颈在连接器出口 4 根 0.3mm 线 + 0.5A/针。
- 底面 7200 颗 LED 但基准点只有 2 个且在顶面; 顶层 8 块 9×9mm 无网络铜皮; 丝印仍是参考板 `ICN-P0.9375...V1.0-LVDS / 2022-10-13`。

🔴 **连接器脚位已与 09-16 PDF 不同(CN1 59/100、CN2 60/100 相同)**; 实测转接板 09-18 版是照 09-16 旧版画的 ⇒ **与灯板 PCB 差 80 个信号脚, 链1/2 与链6/11 还连错了连接器**。✅ **用户 09-18 定: 改转接板, 灯板不动**(改表 `docs/转接板脚位改表_按灯板PCB_2026-09-18.md`)。🔴 **但封装重画与差分对改同排会再动一次灯板脚位 ⇒ 要先把灯板连接器一次定死再改转接板, 否则转接板返工两遍**。见 [[project_pov3d_adapter_v02_review]]。

**How to apply:** 解析 PcbDoc 的现成代码在 `/tmp/.../scratchpad/pcb/apcb.py`+`tracks.py`(olefile; Tracks6 定长 54B: layer/flags/net@3/comp@7/x1y1x2y2w; Pads6 变长要读 5 个长度块; 铺铜产生的走线**没有网络号**, 要靠 polygon index(偏移 5) 归属, 否则会误判"没有地")。
