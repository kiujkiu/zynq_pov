# 验证板灯板原理图审查 (2026-09-17)

原件 `C:\Users\wanqi.liu\Downloads\SCH_0.9375-2260-60S-LVDS_2026-09-16.pdf`(84 MB, jsPDF, 有文字层可机读)。
第 1 页 = 12 颗 2260 + CN1/CN2 (AXK500137YG ×2) + 去耦; 第 2~9 页 = LED 矩阵。
对插方 = 转接板 V01 [[project_pov3d_gw5a_adapter_v01_pin_shortage]]。

## 核过没问题
- 矩阵: 7200 个 2×2 四合一(引脚 B1 G1 R1 B2 G2 R2 T1 T2) = 28,800 px, 360 行线 / 1440 列线全自洽。
  块 HA~HF = 3 行 × 2 列, 每块 80×60 由一对芯片: **奇数 U 的 SACN0-29 管 0-29 行, 偶数 U 管 30-59 行,
  每颗 40 列贯穿全 60 行** ⇒ 一颗的列要靠配对那颗的行管才亮得全。SACN30-47 空。
- 12 颗 P/N 全对; VDDR 2.8 / VDDGB 3.8 / VPP 地 / VCORE 2.2µF / ROW_CAP 4.7µF×2。
- 灯板 CN1↔转接板 CN2、灯板 CN2↔转接板 CN1(位号交叉), 换算 **灯板 k(1-50)↔2k−1, m(51-100)↔2(101−m)** 下 96 信号 + 电源地全对。

## 问题 (已报用户)
1. 🔴 全图只有 12 只电阻(LVDS_EN), **48 対无端接**; 转接板 V01 也只有 0Ω。
2. 🔴 **无电源入口/DCDC/使能**, 3.8V 只有 CN2 10 针、2.8V 4 针。AXK500137YG = **0.5 A/针, 总 10 A, ≤60 mΩ**。
   满流 3.8V 6.1A、2.8V 4.6A、合计 10.7A 全超。09-01 同路径 VDDR 塌到 1.9V([[feedback_vddr_sags_to_1v9_invalidates_fps_limits]])。
3. 🔴 ACK_I ×12 进连接器(CN1.39-62 与 ACK_O 交替、无地), 板上无 100k 上拉。
4. 🔴 两板符号编号制不同(灯板 1-50/51-100, 转接板奇偶), 原理图证明不了焊盘对位; 若排反, 灯板 2.8V(CN2.9-12) 对到转接板地。
5. 🟠 VDDD=3.8V = 绝对最大; SCL/SDA 悬空(参考板有 4.7k); RSTN 无下拉; ACK_O 无上拉; DCLK 悬空。
6. 🟡 **网名双编号**: 数据/时钟沿用级联名(链号), ACK/LVDS_EN 用位号。U8=链4, U9=链5, U5=链6, U6=链7, U7=链8。
   `docs/GW5A转LED转接板_逐球引脚分配_mkxlsx.py:284` 的 `ACK_O{k}` 用位号而 `SCR_D/SCR_CLK` 用链号 ⇒ **链 4~8 的 ACK 与数据不是同一颗**。块 D = 链8+链4, 块 E = 链5+链9。

**How to apply:** 硬件出新版灯板时先按上面 6 条复核; 改 RTL/约束的 ack 索引前先定用位号还是链号。
机读方法: `pdftotext -bbox` 取词; 芯片脚以 `U<n>` 为锚点(脚号 rel x −62~−42 / +58~+72, 网名更外侧); 注意电容位号 `C15` 会和 BGA 脚号 `C15` 撞名。LED 页以 `T1` 字样为锚点。
