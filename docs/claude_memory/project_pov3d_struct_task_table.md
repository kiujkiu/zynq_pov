**用户补充(09-11)**: 结构同事**也管光学** —— 先解决**反光**(亮环境下对比度, "显示器都要解决"), 再是**可视角**
(怎么放置可视角最大、盲区最少), 其余让我补。我补了: 外罩(安全+反光+畸变+**散热**, 现役屏靠旋转风冷静止会过热)、
背景/非发光件黑化、亮环境下光电索引会否误触发。**论据**: 48 W 封顶 ⇒ 不能靠加亮对抗环境光, 对比度只能靠压反光。

结构:
- **版本一 现役转子(macha v4)**: 1-1 现状实测 + **转子判据 v1**(振动限值/时长/测法; 固频要实测) · 1-2 现役转子 900 RPM 达标(偏心装法) · 1-3 光学现状实测 + **光学判据 v1** + 屏体光学要求 v1(→ 硬件 2A-1)
- **版本二 目标整机**: 结构线 2-1 定案(布局/材料/配重/电机) · 2-2 **机械接口契约**(板框/孔位/质量质心上限/大件固定/g 值表, 要在硬件 1-3 过门前冻结) · 2-3 **假负载试转(硬门槛, 不等真板)**; 光学线 2-4 光学方案(反光/外罩/放置/盲区) · 2-5 光学样件验证(现役样机当试验台); 2-6 整机达标 = 与硬件 2C-2 同一次验收
