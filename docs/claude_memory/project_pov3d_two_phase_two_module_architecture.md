# 两阶段 · 两模组 · 一个永久契约 (2026-09-10 用户定)

**用户原话**: 「硬件任务分为 2 个阶段, 验证与生产…最终目标是只有 2 款板子…led+桥与 soc+接口这两个模组
是要求可以满足验证板与生产板通用的, 这样替代可以异步完成」「形态不限制, 由硬件自己把握,
我们只要求板子可替代可异步升级就行」。

## 两阶段的形态

| 模组 | 验证形态 | 生产形态 |
|---|---|---|
| **LED 模组** | 板① 灯板(12 颗 2260) + 板② 桥转接板(ACA420 插件, 邮票孔连接) | **LED 板**: FPGA 直贴 · 24 颗 2260 · 无邮票孔 |
| **SOC 模组** | FS03 开发板 + **板③ CEP→FPC 转接** | **SOC 板**: 自研 FPSoC · 直接出接口 |

🔴 **板③ 是这轮才补上的第三块板**, 此前所有文档都只算了两块。FS03 只有 CEP1/CEP2 两排 2.54mm 排针、
没有 FPC 座 ⇒ 中间必须有一块转接, 而它**不是简单机械转换**(见 [[project_pov3d_fs03_cep_ground_and_third_row]]:
CEP 各 50 脚只有 1 根 GND ⇒ 96 信号 : 2 根地)。

## 🎯 两个冻结接口, 性质完全不同

- **邮票孔 168 焊盘 = 临时接口**。作用是让验证阶段能换 FPGA 子板; **生产阶段随板①+板② 合并而消失**。
- **模组间接口 = 永久契约**。验证与生产都在, 是两个模组之间唯一的边界。
  **只要它冻结, 两侧就能各自异步升级到生产形态, 对方一个字都不用改。**

⇒ **形态自由, 契约不自由**: 连接器形态/机械方案/板形由硬件定; **电气与逻辑契约必须我们冻结**。

## 🔴 契约里两条现在就对不上 —— 不冻结则「异步升级」不成立

### ① 対数按的是验证口径, 不是生产口径

| 色深 | 线速率 | 対/面 |
|---|---|---|
| 8-bit | 800M | **14** ← 当前 RTL `ul_d[12:0]`+`ul_clk`, 灯板文档表 8 的 FPC 也是按这个 |
| 8-bit | 700M | 16 |
| 12-bit | 800M | **20** ← 目标色深 |
| 12-bit | 700M | **23** ← 700M 是时序甜点(余量 16.7% vs 800M 的 2.1%) |

`HW_SPEC_2026-09-04` §C 自己写的是「20 対(12-bit) / 14 対(8-bit)」, 而表 8 的 FPC 写 14 対
⇒ **两处口径不一致, 且 RTL 站在 8-bit 那边**。再叠 [[project_pov3d_uplink_rate_pin_budget]] 的
「协议开销完全没算」⇒ 用 8b/10b 则 ×1.25 ⇒ **12-bit@700M 要 29 対**。

🔴 **対数不够 ⇒ 生产阶段必须换接口 ⇒ 两侧板子都要改 ⇒ 异步升级断了。**
**建议按 30~32 対定, 验证阶段只用 14 対、其余悬空** —— 接口按大的定、小的场景不用满, 这才是「通用」。

### ② 电平与共模没覆盖两种 SOC

```
FS03(验证)     无 2.5V 轨 ⇒ 只能发 LVDS18, VOCM 0.3 / 0.6 / 0.8 V
自研 SOC(生产)  有 2.5V 轨 ⇒ 可以发 LVDS25, VOCM 0.9 / 1.25 / 1.4 V
                                            ↑ 两者差近 1 V
```
若 LED 侧接收只按 LVDS18 设计, **换自研 SOC 板时 LED 板要改** ⇒ 异步升级又断了。
⇒ **接收侧要同时覆盖两个共模窗, 或留 AC 耦合位**(与灯板那 60 个逃生位、板③ 的共模再偏置位同思路,
只是这次是为了「换 SOC 不动 LED」)。

🔴 **这条此前所有文档都没提**, 因为之前没人把「换 SOC 侧不动 LED 侧」当成硬要求。

## 契约要冻的四条(任务 A6)

1. **対数** — 按生产口径(12-bit)定
2. **电平与共模** — 覆盖 LVDS18 与 LVDS25 两个窗
3. **阻抗与地线** — 100 Ω ±10% · G-S-S-G
4. **lane 映射与协议** — 校验 lane 位置 · 训练序列 · 对齐图案 · 用不用 8b/10b。
   🔴 **协议至今完全没拍板, 而它直接决定第 1 条**

## 屏体路线: COB 打样 3 个月(采购 09-10 回复)

屏体规格要等验证板硬轴闭合才能定 ⇒ 最早 11 月中下单 ⇒ **2027-02 中到货, 撞春节停工窗**。
而整机排期里其它环节的机动空间加起来都不到 3 个月。
⇒ **自制的理由不是成本, 是周期与迭代次数** —— 验证板大概率不止做一版, COB 一版 3 个月 = 一次改版吃掉一个季度。
⚠ 仍缺: 自制的单位成本与良率 · P0.78 间距下自制的工艺可行性。**自制不等于便宜**(整机 82,944 px 是最大一笔)。
