## 当前在做: ③ 的 η 实测

判据: 两个 `pov_slice_v2` 各挂独立 HP 口并发跑 603 片, 每片 ≤110.6 µs 且同时。
η = (2 × 82,944 × 603 / 墙钟) / 2.133 GB/s。**先用已知带宽负载标定量具, 不通过不测 IP。**
⚠ LXB 昨天用的是纯 RTL 顶层无 PS ⇒ 要另起 PS+HP 的 BD; 或换 FS03(要先比 DDR 是否相同)。
workflow `wf_26d6e3d7-84a` 在准备 build_eta.tcl / run_eta。
