# 手册有两版, 资料包里那份是草稿 (2026-08-27 发现)

## 🔴 事情本身

米联客资料包 `03_MLKPAI_FS03_DR1V90GEG/.../DS1200_DR1_Datasheet-米联客.pdf` 是
**0.4 草稿**, 全文 **215 个 TBD**。
而 **`V1.0 首次发布正式版本`(2024/07/25)** 在用户的微信文件里
(`xwechat_files/.../msg/file/2026-07/DS1200_DR1_Datasheet.pdf`), **0 个 TBD**,
而且**表号整个重排过** —— 不是同一份填空, 是重新组织的正式版。

**我拿草稿当权威, 得出了"DR1 屏接口走不通"的错误结论。**

## ⚠ 唯一还卡着的电气项: 输出共模 VOCM

正式版 `表 3-14 LVDS 直流规格(PL I/O)`, VCCIO=2.5:

| | 最小 | 典型 | 最大 |
|---|---|---|---|
| DR1 **VOCM** 输出共模 | **0.9** | **1.25** | **1.4** V |
| ICND2260 要求 **VIC** | **1.1** | — | **1.3** V |

⇒ **典型值 1.25 V 正落在窗口中心, 但 min/max 两端都超窗** ——
**典型片能工作, 器件级没有保证。** 这是唯一一条真要问安路的电气问题。

其余对得上: VOD 差分摆幅 200/350/400 mV 落在 2260 的 VID ±100~600 内 ✅;
片内端接 RT 65/100/135 Ω; VID 输入摆幅 100/300/400 mV; VICM 输入共模 0.9/1.25/1.4 V。

## 🔴 因此作废的结论

- ~~"DR1 上没有任何一条能跑到 333 Mbps 的 IO 路径是有厂商数据支持的"~~ —— **错**, 真 LVDS 1250 Mbps。
- ~~"DR1 独有的两条致命短板: 单端 300 < 333 / LVDS 参数全 TBD"~~ ——
  第二条**直接消失**; 第一条降级为"不必走单端那条路"。
- ⇒ **DR1 在屏接口上不比 7020 差, 可能更好**(7020 的 OSERDES 是 950 Mb/s, DR1 LVDS 是 1250)。
- ⇒ 记忆 [[project_pov3d_final_target_chip_verdict]] 里"DR1 独有五条短板"要按此收窄。

## DDR: 芯片支持 32-bit, 是**板子**只贴了 16-bit

- `DS1200 §2.1.3` + `表 3-45`: 支持 **8~32 bit**, 最高 **1066 Mbps**
- `DS1201 表 4-1`: `SDRAM 16/32-bit DDR3/DDR3L/DDR4`(两处独立出处)
- FS03-DR1 硬件手册: **"DDR3L 的总线宽度共为 16bit"**, **"DDR(片): 1 片"**(GDP2BFLM-CB)
- 而现役 FS03 **Zynq** 板同样是单颗 16-bit
⇒ **两块开发板都只贴了一半位宽。换芯片解决不了, 换板子(两颗 x16 并联)能解决。**
⚠ 板卡资料写的 1333 Mbps 是**颗粒**额定值; SoC 侧封顶 1066 ⇒ 按 1066 算。

## 🔴 缺的那本: UG1214

`DS1200 V1.0` 两处点名引用 **《UG1214_安路科技 DR1 系列 FPSoC 产品说明书》**
(`:924` 启动模式章节 / `:1971` **"PL 侧复位可通过 PS 侧寄存器配置进行软复位"**),
而**全盘没有这一本**。

资料包里有 UG1201(PLB)/1202(ERAM)/1204(DSP)/1206(PLL)/1210(IO)/1212(ADC) ——
**全是 PL 侧模块手册, 唯独缺讲 PS 的 1214**。
⇒ 它很可能一次性解掉"PS 寄存器/软复位/`0xF8806330`""HP 拓扑与仲裁""QoS 语义"三条。
**先要文档, 再问参数。**

## 剩下要问安路的只有 4 条

1. **能否提供 UG1214？有没有 PS 侧寄存器手册(TRM)？**(排第一, 可能带走后两条)
2. **VOCM 的实际分布？**能否保证落在 1.1~1.3 V
3. 两个 HP 口在 DDRC 前是否合流成单条 `HP_BUS`？仲裁策略？
4. DDRC 的 QoS 数值语义？

## How to apply

🔴 **遇到 TBD 密集的手册, 第一反应该是"这是不是草稿", 而不是"这个参数厂商没测"。**
本项目据草稿做了一整轮选型判断, 结论方向是反的。
⚠ 供应商资料包(米联客转发的)不等于原厂最新版 —— **直接向原厂要正式版**。

顺带: 屏那边同理 —— `ICND2260_datasheet_CN_2023_V1.7.pdf` 早就在用户微信文件夹里
(记忆里挂了很久的"待索取 V1.7"其实已到手), 里面确认
**`FDCLK Max: 25MHz(TTL-DDR) / 170MHz(mini-LVDS)`**(我们要 160, 在规格内)
与 **VIC 共模窗 1.1~1.3 V**。
