# 转发延时寄存器: 手册里不存在, 而且我们不可能配错它 (2026-09-02)

## 事实一: 全文只有 1 行提到它

对 `pg.txt` + `ds.txt` 全文搜 "延时 / 相位 / 偏斜 / skew / delay", **合起来只有一处命中**:

```
ds.txt:452  注释 1: 对于 mini-LVDS 驱动端, 传输延时可设置为 1/8tLVCP, 1/4tLVCP 或 3/8tLVCP
```

"相位"一词出现 **0 次**。`0x1a` 全文只出现 4 次且只提 bit9;
`0xb0~0xbf` 整块只有 `0xb4[5:4]`(通道数)有定义; §11 是纯数值表、**没有任何字段名**。
⇒ **没有寄存器落点。这是"手册没写", 不是"我没找到"。**

## 事实二: 🔴 我们不可能把它配错

`0xb0~0xbf` 整块与**确凿在跑 mini-LVDS 的供应商抓包**逐位相同:
`b0=0060 b1=1155 b2=2804 b3=3100 b4=3020 b5=0054 b6=0021 b7..bf=0000`, 一处不差。
我们与手册默认差的那两位(`0xb0[4]`、`0xb4[3]`)也和抓包一致。

⇒ **238 个寄存器里没有任何一位 PHY 位是我们独自动过的。**
⇒ 🔴 **"转发相位被我们配错"这个假说在逻辑上不成立** —— 我们从来没有能力设它。
**请把它从"我们的配置错误"清单删掉, 只留在"问供应商"清单。**

## 事实三: DS 第 9 页那两行是**输出**规格, 不是输入要求

`tSTU = tHLD = 1/4 tLVCP` 两者相加 = 整个位周期 ⇒ 那是"眼图完全居中且零抖动"的**理想值**,
不是带余量的窗口。而且**最小值一栏是空的**。
⇒ 🔴 **手册对 mini-LVDS 接收端的 setup/hold 一个数都没给, 所以 9 颗级联的时序余量算不出来。**
任何"按手册算余量"的推理都要先声明这一点。

## 要问供应商的两句(可直接复制)

> ① DS V1.7 第 9 页注释 1 的三档传输延时, 由**哪个寄存器的哪几位**控制? 上电默认哪一档?
> ② 同表 tSTU/tHLD 只有典型值、最小值栏空白。这两行描述的是贵司芯片**转发输出端**的特性,
>    还是对**接收输入端**的要求? 若是前者, 请补充接收端建立/保持时间的**最小值**规格。
