# ICND2260 的原厂与代理 (2026-09-09 用户澄清)

**用户原话**: 「这个芯片供应商是集创北方」。

| | 谁 | 干什么 |
|---|---|---|
| **原厂** | **集创北方 (Chipone Technology)** | ICND 全系产品线的制造商。datasheet 都在 `dr1v90/docs/vendor/chipone/` 下 |
| **代理** | 深圳映己鸿鹄科技有限公司 | 我们实际对接的一方 |

## 为什么会混

库里此前**一次都没出现过「集创北方」**, 只有映己鸿鹄, 因为技术往来全走代理:
- `2260lvds.xlsx` 那份 238 行寄存器表是映己鸿鹄发的(见 [[project_lxb_icnd2260_bringup]])
- `ICND1069_编程指导_CN_2024_V1.2_深圳映己鸿鹄科技有限公司专用.pdf` 打的是他们的水印

⇒ 于是 `BOM_询价单_2026-09-08` 的 B02 行把型号写成了 **`ICND2260（映己鸿鹄）`**, 与其它行的惯例矛盾
(A01/B01 括号里放的都是原厂, 如「安路」)。**已改为 `ICND2260（集创北方 Chipone）`**,
说明列注明「原厂集创北方, 现有技术对接走代理商深圳映己鸿鹄」。

## 怎么用

- **问价** 找原厂集创北方或其代理都行。口径 ~5 元/片(`project_status.html:836`), 单机 48 颗, 是屏板上仅次于灯珠的一笔 ⇒ **值得原厂与代理各比一次**
- **技术问题** 继续找映己鸿鹄。待发的问询清单见 `灯板改板_邮票孔FPGA接口_2026-09-09.html` 表 13 的 #2/#5/#11/#12 + IIC 几条
