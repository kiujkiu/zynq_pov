# 给集创北方的问询单 (2026-09-20)

文件: `zynq_pov/docs/问询单_集创北方_ICND2260_2026-09-20.md`(可直接发出, 末尾留了联系方式栏)。
按阻塞程度排序, 前两组直接决定 PCB 要不要改版。

## 🔴 第一组最关键: 60 扫配对 + 独立链路
**新发现的依据**(2026-09-20 查手册):
- 编程指导 V2.8 **§2「级联模式」**原文+配图: 两颗行列共用驱动 80×96, **芯片A 的行驱动管第 1–48 行, 芯片B 管第 49–96 行** ⇒ "某颗在对方那半扫描期间完全不开行管、只出列电流"是官方模式, 不用另想办法。
- 寄存器: **`reg0x04[13:8]`=芯片一扫数 / `reg0x04[5:0]`=芯片二扫数, 总扫描数=两者之和(各最大 48)**; **`reg0x08[0]`=扫描扩展模式使能**。
- 厂家 `2260lvds.xlsx`(45 扫单颗) 佐证字段含义: `0x04=0x2d00`(45+0)、`0x08` bit0=0。⇒ 我们 60 扫应为 `0x04=0x1E1E`、`0x08[0]=1`。
- 🔴 **但"每颗独立链路"没有依据**: 该节标题是级联; 协议里芯片身份唯一来源是级联序号(`DEVICE[3:0]`「第1级联设备等于0」, `VHEAD[19:16]`级联芯片数, 显示数据按级联顺序发); 手册**没有任何"我是芯片一/芯片二"的寄存器位**; SEL_I/SEL_O 只标"测试用"。参考板本身就是 12 颗串一条链。
- 🎯 **09-20 用户把问法换了(更好)**: 不问"怎么区分 A/B", 直接问「**能不能让某颗在指定扫描时隙完全不开行管、只出列电流**」—— 只要同一时刻只有一颗行驱在工作就行。问询单第一组已按这个重写(11 问)。
- 手册里**没有**任何"关行驱"的寄存器; 能关的只有整颗(黑屏节能 reg0x59[13]+reg0x1c[13:12] / 休眠, 都不能按时隙控制)。最接近的两处: **空行**(§8-16「扫描数用不满时空行必须排布在每颗芯片的最后」—— 正好是第二颗需要的反面) 与 **可编程扫描顺序**(datasheet 首页有, 编程指导全本没有这组寄存器)。默认表 0xa6~0xad = a5a5/1842/5a5a/2184/a5a5/4218/5a5a/8421 像某种映射表, 已一并问。
- 🔴 **默认寄存器就是配对模式**: §11 默认 `0x04=0x2d2d`(45+45)、`0x08=0x5105`(bit0=1 扩展模式启用); 厂家 45 扫单颗配置是主动关掉它。
- §5 数据顺序: Chip#0→Chip#1…每颗按 Line#0…、每行 40 像素; **每颗收的行数 = 总扫描数**(它的列要覆盖全部行)。
- 退路: ①每对串 2 颗(灯板加 SDO→SDI, 只 2 跳, 但每链数据翻倍/帧率减半) ②要到"可编程扫描顺序"寄存器(datasheet 首页有这条特性, 编程指导没写)。

**How to apply:** 答复回来后先更新 `改板结论_验证板_2026-09-18.html` §3 与灯板改版决定; 配对模式的寄存器示例拿到后进 `icnd2260_regs_vendor.mem`。

## 🔴 2026-09-21 厂家答复 + 用户决定
**用户转述: "厂家没做过的都说没有, 只提供普通使用"** —— 第一组 (独立链路配对 / 指定时隙不开行 / 可编程扫描顺序) 一律"没有"。
⇒ 📌 **对这家的规矩: 非标准用法别指望厂家背书, 问询只能拿到普通用法的参数; 要证据只能自己上板。**
用户 09-21 定: ① 灯板配对两颗的 SDO→SDI **预留 0Ω**: 必须 1串2 就 60 扫 **4,300 fps**@166.67 (帧头不翻倍, 是 50.5% 不是严格减半;
🔴 不够 503 片×900 RPM 的 7,545, 只到 ~510 RPM 或 286 片; 48 扫压测也只有 5,363), 1串1 才有 8,523 (48 扫 9,045);
② **先在现有 E104 + 9 颗样板上验** —— 见 [[project_icnd2260_pairing_mode_bench_0921]]。
