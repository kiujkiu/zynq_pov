# ICND3019（行管 / NMOS 共阴行驱）

身份：被动行选 IC，串行译码 + 16 路 NMOS。**不参与灰度**，只把对应行拉到 GND。
一颗管 16 行 → 64 扫屏需 4 颗串联。

## 管脚 (SSOP24)
| pin | 功能 |
|---|---|
| 2 | SDI（串入；每帧只移一个"1"，选中哪通道哪行就亮）|
| 3 | DCLK（**每次上升沿换行**，高电平宽度=消影时间，建议 >500 ns）|
| 4 | RCLK（寄存器配置时钟，仅初始化时用）|
| 5-12, 17-24 | OUT8-15, OUT7-0（NMOS 输出，导通 130 mΩ，1.5 A 持续）|
| 13 | GND |
| 14 | SDO（串出给下一颗）|
| 1, 15 | VDD（3.0~5.5 V）|

## 协议
1. **行扫描**：每个 DCLK ↑ → SDI 数据移一位 → 输出通道同步移位（输出低电平 = 选中那行）
2. **寄存器配置**：DCLK **低**电平窗口里发 N 个 RCLK 上升沿，`Reg[3:0] = N - 8`
3. setup/hold = 30 ns；tPHL ~134 ns、tf ~160 ns（输出 turn-off 较慢，要预留消影时间）

## 4-bit 寄存器
| bit3 | bit2:0 | 行为 |
|---|---|---|
| 0 | 000-111 | 增强模式，消隐电位 1.5~3.0 V (@5V) / 1.14~2.28 V (@3.8V) |
| 1 | 000-111 | 普通模式，电位档位同上 |

- 默认 `<3:0>=1101`（普通模式，2.5 V 消隐）
- `<3:0>=0000` 或 `1000` 仅在配合 ICND1069 开路检测增强模式时使用

## 应用约束（数据手册原文）
1. 通道必须从 OUT0 顺序使用，不能跳通道
2. 扫数中间不能有空闲通道
3. 扫描组的初始数据只能从排线后的 245 引入，不能从上一扫描组的输出引入

# ICND1069 + ICND3019 系统集成

- **DCLK 不共用**：1069 的 DCLK 是连续高速时钟（PWM 数据，4~16 MHz）；3019 的 DCLK 是低速"换行脉冲"，频率差几个数量级
- **典型连法**：1069 的 ROW 输出 → 3019 的 DCLK 输入
  - 每完成一行 PWM，1069 发 ROW↑ = 3019 收到一个换行脉冲 = 3019 把"1"移到下一行 NMOS
  - 第一组第一行 ROW=W12（12 DCLK 高），其他行 W4 —— 但 3019 只看上升沿，宽度差异不影响它
- **RCLK 只在 init 时配一次** 3019 的消隐电位档位；运行时不再动
- **SDI**：1069 用 SDI 接灰度数据；3019 的 SDI 在帧开始时灌一个"1"，之后只靠 DCLK 移位
- **PCB 上的 74HC245**：用作行管段间总线驱动（数据手册原文："扫描组的初始数据只能从排线后的 245 引入"）
