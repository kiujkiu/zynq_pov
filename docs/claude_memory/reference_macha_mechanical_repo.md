**POV3D 的机械结构件跟电子/软件是两个工作区, 别在 pov3d 里找 CAD。**

| | 路径 | 内容 |
|---|---|---|
| 电子/软件 (本仓) | `D:\claude_workspace\pov3d\` | RTL / Vitis / host 推流 / 记忆库在 `zynq_pov/docs/claude_memory/` |
| **机械/3D** | **`D:\claude_workspace\macha\`** | `pov3d/` = manifold3d 建模仓 (v2/v2.1/v3/v3.1/v4), **`memory/` = 它自己的记忆库** |

macha 侧结构 (每个版本一个目录): `assembly_vX.py` 总装脚本 (唯一入口, 出整机 STL+PNG)
+ `models/<件名>/build_*.py` 逐件生成 + `print/` 打印清单与 README。
坐标系 = 底板顶面 Z=0, Z 向上。整机高 307.95, 最大半径 115.07。

## 版本线

- **v3** 双面屏 (屏模组 13.4×150×168.75 居中, LED 面 X=±6.7)
- **v4** 底板换 200×200×13 网格板 (4 安装孔正好落 (±75,±75) = 现有柱位, 上层全沿用)
- **v3.1 (2026-07-30 起, 当前实验版)** = **偏心屏**: 模组整体 +6.7 让一面贴轴,
  LED 面变 **X=0 / X=+13.4**, 消掉中心 Φ13.4 盲柱。底座沿用 v4。
  4 个新件: `portal_tee_v3_1`(屏孔做 **3 个离散孔 −6.7/0/+6.7**, 破"同件转180°"死结,
  **拧不同孔即可在居中↔偏心间切换, 不必重印**) / `top_cap_v3_1_1`(压条 18→32 宽)
  / `rotor_shroud_v3_1`(屏缝非对称 −7.0..+13.7, 同时覆盖两种落位) / `vane_slider_v3_1`。
  ⚠ **动平衡未解决** (偏心 6.7 × 屏质量; 主配重放不下, 只剩 rim_ring 2 个 Φ4 孔) →
  **实验先低速跑 ≤850 RPM** (已有涡动, 临界 1200–1600 RPM)。

## 为什么软件侧要关心

屏面到转轴的垂距是**渲染切片的几何参数**, 机械一改软件必须跟着改, 见
[[project_pov3d_offset_axis_geometry]]。v3.1 的偏心还顺带打破了双面屏的对称等价关系。

⚠ macha 侧记录的经验之一: 偏心弦布局的干涉判断, **径向带比较法和 (r,z) 占位法都会给出
错误结论, 只有布尔全周扫掠 (1°×360) 可信**。
