# Z0 探头（电阻分压探头）自制 (2026-09-11)

## 为什么有源探头那么贵 —— 四个真实原因

1. **难点在探头尖，不在放大器。** 要做到 <1 pF 输入电容，输入 FET 必须物理上就在针尖里
   （任何引线长度都是电感）⇒ 那是个微型混合电路（激光调阻薄膜电阻网络 + 裸片），不是一块 PCB。
2. **逐支标定。** 多 GHz 平坦度做不到靠设计保证，每一支要上矢量网分实测、把频响修正系数
   写进探头，示波器通过 AutoProbe 读出来做数字校正。**这道工序占成本很大一块。**
3. **量产量是几千支不是几百万支**，研发和产线摊销全压在这个量上。
4. **AutoProbe 是封闭接口**，只能原厂买，无竞争；探头尖/焊接头本身还是消耗品。

🔴 **别自制有源 FET 探头**: 分立 JFET 源极跟随器认真做也就 300–500 MHz / 2–4 pF，
**比 Z0 探头还差**，白费功夫。

🎯 **Z0 探头不是廉价替代品，是主动选择** —— 带宽比同价位有源探头高、输入电容更低、
没有有源探头的过载和非线性问题。高速测量里很多人本来就优先用它。

## 配方

**材料**（单点成本约一块钱）:
- 薄膜电阻 0402，**450 Ω（10:1）** 或 950 Ω（20:1），1% —— **要薄膜不要厚膜**
- RG-178 细同轴，或 0.047″ 半刚同轴，**越短越好**（<30 cm）
- SMA 公头 + SMA→BNC 转接（Infiniium 9000 系列输入是 BNC + AutoProbe 环）
- 可选：串联 10 nF 0402 做 AC 耦合

**做法**:
1. 电阻一端**直接焊在被测焊盘上，引线长度为零**
2. 同轴芯线焊到电阻另一端
3. 🔴 **同轴屏蔽层焊到紧邻的地，距离 <2 mm —— 这一步决定带宽**，比选什么电阻重要得多
4. 示波器通道设 **50 Ω 输入**，衰减比填 10:1 / 20:1，读数就是实际电压
5. 两路做差分时用 **channel deskew** 校齐两根同轴的长度差（9000 系列支持）

## 分压比: 默认 10:1（8-bit 机上这个要算）

| | **10:1（450 Ω）** | 20:1（950 Ω） |
|---|---|---|
| 350 mV LVDS 到示波器 | **35 mV** | 17.5 mV |
| 被测点看到的负载 | 500 Ω | 1 kΩ |
| 线上反射扰动 | −4.7% | **−2.4%** |
| 直流抽流（若 DC 耦合） | 2.4 mA ❌ | 1.2 mA ❌ |

既然都要 AC 耦合（直流负载因此归零），**默认用 10:1** —— 8-bit 机上多一倍的信号幅度
换来实打实的信噪比，而 4.7% 的反射对判断"眼开不开"无所谓。只有特别敏感的节点才退到 20:1。

⚠ **09-11 修正**: 初稿写的"950 Ω / 20:1"已改为"默认 10:1，敏感点用 20:1"。

## 🔴 必须走 AC 耦合

直流耦合时对地抽约 **1.2 mA（20:1）/ 2.4 mA（10:1）**，而 LVDS 驱动器总电流才 **3.5 mA**
⇒ **把共模拉走几十 mV，而余量只有 6 mV**（见 [[reference_scope_and_probe_requirement]]）。

⇒ **Z0 探头只用来看边沿，共模另用高阻手段单独量 —— 两件事本来就该分开测。**

## 🔴 两条安全提醒

1. **示波器 50 Ω 输入有最大输入电压限制**（这一代通常 5 Vrms 量级），
   **烧了是修主板不是换探头**。20:1 下 3.8 V 轨只到 190 mV 没问题，但
   **电阻虚焊或碎裂时全压直灌 50 Ω**。焊完先用万用表确认分压比再接示波器；
   高压轨（24 V 定子侧、3.8 V VDDGB）一律用无源探头。
2. 焊点会在被测线上引入不连续（−2.4% @20:1 / −4.7% @10:1，可接受），
   但**别在一条线上同时挂三四个 Z0 探头**。

## 🎯 不需要预先设计的测试点 —— 现役板也能用

⚠ **这条更正了 09-11 早先写的"现役 2260 板已投产、焊不进测试点 ⇒ 仍需一支真探头"。**

Z0 探头焊在现成的可焊点上就行，板上到处都是:
- 🎯 **B06 那 96 只 100 Ω 端接电阻的焊盘**（紧贴 2260 的 G1/G2、D1/D2…）
  —— 最理想，本来就在链路末端
- 过孔、J1 连接器引脚、任何裸露焊盘

⇒ **现役 2260 板一样能用 Z0 探头 ⇒ 那笔有源探头的钱可以先不花。**

新板上询价单 B17 已给每対时钟留了"分裂端接 2×49.9 Ω + CM 测试点 + AC 耦合位"，
把这个思路扩到上行差分対上即可。

## 与买有源探头的诚实对比

| | 自制 Z0 探头 | 二手 1156A/1157A |
|---|---|---|
| 带宽 | 2–4 GHz（看地回程） | 1.5 / 2.5 GHz |
| 输入电容 | <0.5 pF | ~0.3–1 pF |
| **输入阻抗** | **1 kΩ（AC 耦合后只剩交流负载）** | **100 kΩ** ✅ |
| **手持到处探** | ❌ 必须焊死 | ✅ |
| **DC 耦合量静态电平** | ❌ 会拉走电平 | ✅ |
| 换点 | 每点重焊一套 | 随手移 |
| 成本 | ~¥1/点 | 待询 |

🎯 **决策规则: 点位已知、能焊死、只看边沿和眼图 → 自制。
要边找边探、要量 DC 电平 → 买一支单端有源。**

而两个共模悬案本身是 DC 的（1 MΩ 无源探头或万用表就够），
剩下"到处乱探找问题"的场景在 200 MHz 以下由便宜二手无源探头覆盖
⇒ **大部分情况不用买。**
