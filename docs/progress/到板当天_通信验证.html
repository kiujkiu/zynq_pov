0.1 先讲结论

  • 硬件一次定型, 不改板: SoC 底板 H1/H2 实物只能插在 FS03 的 J12/J11 (与设计意图相反), 所以主控位流一律 POV_HSWAP=1 (CEP1 头座脚 n 的球 ↔ CEP2 头座脚 n 的球): 面 A 进 bank11, 面 B 进 bank33; 面 A 上行 PLL 钉在 x0y0z0。⇒ J1 与 J2 都要 2.5 V。
  • 已通的: 电源与电平、边带三线 (UART / ALIGNED / RST) 双向、握手 C1、13 lane 静态连通 + 极性 (用诊断位流)、转发时钟 100.000 MHz。
  • 没通的: 高速接收。桥的 IDES8 实际按半速采样 (桥上行 PLL 配置问题), 不是线、不是电平。D76 在修; 修好前 C2 (对齐) 和 C3 (PRBS) 不会过, 别在它们上浪费时间。
  • 桥位流更新暂用 PC 下载器: 远程由主控灌桥 SRAM 暂不可用 (预检 TMS/TDI 读到 0, 在查因; 面 A 单装 TDO 不回主控 H-3, 只能盲灌)。所以本页命令里的 --bridge-load sram 在查清前不要用, 改 --bridge-load pc。
  • 主控开机演示已关 (卡上有 pov/nodisplay), V0 位流不会在 bank11 上和桥对驱; FPC 可以常插 (只有 PC 下载器下载桥时才要拔 FPC)。
