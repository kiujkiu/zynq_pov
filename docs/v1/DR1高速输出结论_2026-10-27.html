DR1 高速输出上板结论（2026-10-27）

板dr1m90-01，面 A，GW5A 桥接收分支task/d84-dr1hsio，D84 提交 b20d569

一句话：DR1 主控到 GW5A 桥的 LVDS 高速输出已经跑通。V1 用 600 Mbps（已定，1 小时 0 误码）；V2 需要的 1.2 Gbps 在“DR1 发、GW5A 收”这一层已可行：加预加重后 13 lane 全锁，10 分钟 0 误码。

时间线

  • 上午：400 / 600 Mbps 正常，700 / 750 / 800 Mbps 丢位，800 Mbps 只输出偶数位。
  • 查到根因：PLL 奇数分频时 DUTY_INT 配错。全仓改正，800 Mbps 偶数分频和奇数分频都通过。
  • 继续上 1.0 Gbps：3 条 lane 约 1% 误码。上 1.2 Gbps：约 3% 误码，PRBS 不锁。
  • 打开 bank 级预加重后，1.2 Gbps 13 lane 全锁，10 分钟 0 误码。

根因

奇数 PLL 分频时，CLKC0_DUTY_INT 要取 INT(DIV/2)+1（UG1206 §2.5.4 公式 2-5），代码里写成了 DIV/2。700 / 750 / 800 Mbps 三档都是 DIV 5，全部踩中。TD 对这种配置不报警，时序也报 0 违例，所以只能上板才发现。

对 V1 / V2 的影响

  • V1：用 600 Mbps，不受影响，已长跑验证。
  • V2：1.2 Gbps 的链路风险从“能不能发”降为“长跑、真帧格式、V2 p2 桥”的工程验证。
  • 核心板：FS03 核心板的 LVDS 线上串了 33 Ω 排阻（R201–R208 等），怀疑是码间串扰来源。自研核心板 LVDS 线不放串阻。
  • 代码：所有奇数分频位置都必须按公式 2-5 取值。
