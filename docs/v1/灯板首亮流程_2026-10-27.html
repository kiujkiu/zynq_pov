V1 灯板首亮流程 (ICND2260, 11-05 到货当天)

一条命令: bash d86_panel_day/灯板首亮.sh <板名> [--load-main 主控位流.bin] [--long 10m]。离线演练: 加 --dry-run --yes。每步打 PASS/FAIL 判据, FAIL 附最可能原因与下一步。

安全: 灯板断电接线; 灯板这一路电源先限流 1 A; 全程从黑场 + 安全电流(bright 0)起步, 首亮亮度不超 25; 灯板不转无风冷, 温度 > 75 度自动中止; 手边备红外测温枪。

第一步 人工确认(脚本会问)

  1. 灯板在断电时接到桥转接板(CN1/CN2 方向核过), 桥/灯板/主控同一次上电, 不带电插拔。
  2. 电源限流 1 A(安全档全屏白估 20 mA; 出厂电流全白满灰度约 1.07 A + 12 颗 2260 自身电流[待硬件给])。
  3. SDO->SDI 级联 0 欧已补; 链首组 0 欧贴、伙伴组不贴; R176-R181 贴没贴(不贴用 --ack-devs 0)。
  4. 无风冷: 全程低亮, 摸背面或红外枪量温。

第二步 自动阶段

阶段做什么PASS 判据
P 前置连板、位流指纹、没人占板、桥身份SLP3/ULK1/SBD1/FMTC, GEOM 12-bit, 桥帧兼容
A 安全态黑场 + 电流安全档, 记桥 uptime桥黑场、uptime 不回落
L 链路ul fwd 2 -> train -> ALIGNED -> go序列器 RUN, 帧在涨
K 逐链 ACK6 链 x 2 芯片读 0x00每链回包 ok>=1, bad=err=tmo=0, 数据 0F3C
R 读寄存器0x04/06/08, 0x2D/3D/4D, 0xFC= 期望值(电流=安全档), 温度合理
B 亮度写入黑场下 bright 50, 回读, 写回安全档逐链回读 = 新值(写不进 FAIL)
C 纯色白/红/绿/蓝低电平; 亮度 0/17/25 台阶上行校验和 = 预测, 桥无错, 人看 6 块, 温度 <= 60
I 图样块号、逐链单块、棋盘、隔行、隔列、灰阶逐像素自证 + 人看
T 真内容walking 内容, 假转 12 rps触发 ~4284/s, 发片=触发, 无丢片, 无 NAK
Z 长跑d73 run.sh --panelACK 错 = 0, 前后温度
S 收尾停出片源、γ 回默认、安全档、黑场全部到位

失败时

某链无 ACK: 查 ACK 上拉/R176-R181/灯板连接器; CRC 错: 查 CRC 位序与 ACK 线毛刺; 亮度写不进: 查写表是否生效/被覆盖; 桥中途复位: 已自动重下黑场并中止, 查供电。退出码 0 全过 / 1 有硬 FAIL / 2 前置不满足。结果在 d86_panel_day/runs/<时间>_<板>/report.txt。

要问硬件

  1. 网表: CN1/CN2 方向与引脚; 面 A/面 B 各接哪块灯板; 级联 0 欧。
  2. 2260 链数(6 链 x 1 串 2)、链号与 P1-P6 对应、每链两芯片先后。
  3. ACK 通路: R176-R181、ACK_O/ACK_I 上拉、电平转换。
  4. 供电时序: 是否同次上电、RSTN 谁拉、上电顺序、可否带电插拔。
  5. 电流: 灯板限流值、2260 自身电流、是否需风冷。
