结论：两块板都还不能投板。两块板之间的 FPC 对插逐脚对得上（70 导体同名，40 对 LVDS 的 P/N 全对），问题集中在电平转换接反、电源断路和 JTAG 拓扑。

桥转接板这版做对了两件大事：VCCIO45 已回 3.3 V；JTAG 转换 U18 补了上下拉、OE 电阻和本地下载座。但新加的边带转换 U19 两侧接反了。

SoC 转接板：2.5 V 那路 DCDC 没有输入；两块桥的 JTAG 串成了菊花链。整板还有一个前提：DR1 底板 bank33 / bank11 要改成 2.5 V。

B1

桥：边带转换 U19 两侧接反

必改 · 本版新引入
现状
U19 = SN74AVC4T774PWR。VCCA（16 脚）= PWR2V5，VCCB（15 脚）= VCC3P3，旁注写 "A接主芯片 FPC / B接桥BTB 3.3V"——器件和供电都对。但连线相反：
  • A1–A4（3–6 脚）经 R228–R231 接 B4_B29_N / B4_B52_N / B4_B39_P / B4_B39_N（GW5A 侧）；
  • B1–B4（14–11 脚）经 R224–R227 接 DR1V_ACK / DR1V_RST / DR1V_UART_RX / DR1V_UART_TX（FPC 侧）。
改法
两侧网络对调：A1–A4 接 DR1V_ACK / RST / UART_RX / UART_TX，B1–B4 接 B4_B29_N / B52_N / B39_P / B39_N。DIR 不动（DIR1..4 = L / H / L / H，对调后正好是 ACK 桥→SoC、RST SoC→桥、UART_RX 桥→SoC、UART_TX SoC→桥），与 U18 画法一致。
原因
按现在连线四路方向全反：ACK、UART_RX 变成 FPC 驱动 GW5A，与 GW5A 输出对冲；3.3 V 侧输出打到 DR1 的 2.5 V 口。
B2

桥：U19 上下拉放在了 GW5A 一侧

必改 · 与 B1 一起
现状
R235（10k 到 GND）挂 B4_B52_N，R236（10k 到 GND）挂 B4_B39_N，都在 GW5A 侧。
改法
DR1V_RST 加 10k 下拉到 GND；DR1V_UART_TX 加 10k 上拉到 PWR2V5；R236 删除（或改上拉到 VCC3P3）。R235 可保留。
原因
FPC 未插时 U19 的输入在 FPC 侧悬空，桥收到的复位不确定；串口线被下拉到地等于持续发 break。
B3

桥：核心板座子 CN3 / CN6 脚号仍是 101−n

必改或用 PCB 证明
现状
CN 区域整体下移，脚号文字逐字未变：VCC3P3 仍在 97–100，FPGA_TCK 在 1。
改法
恢复 09-23 的 n→n；或提供 PCB 截图：核心板 P1 第 1 脚落在本板哪个焊盘，证明 VCC3P3 对上核心板的电源脚。
S1

SoC：2.5 V DCDC 的输入脚接在孤立网上

必改
现状
U5 STI3411A 的 VIN（4 脚）接 PWR5V，该网全图只出现 1 次，只挂 C28 / C29，没连到 VCC_5V；EN 经 R157 接的才是 VCC_5V。很可能是从桥板复制时网名没改。
改法
VIN 接 VCC_5V。
后果
PWR2V5 永远不出电，H7 / H9 两个座子没有 2.5 V。
S2

SoC：两块桥的 JTAG 串成菊花链

必改
现状
  • TDI：CEP1_24N → R2 → FPC1-68（桥 A）；
  • 桥 A 的 TDO（FPC1-67，FPGA1_TDO）→ R6 → FPGA2_TDI → FPC2-68（桥 B）；
  • 桥 B 的 TDO（FPC2-67）→ R5 → CEP1_24P；
  • TMS = CEP1_4P、TCK = CEP1_4N，经 R3/R7、R4/R8 同时送两边。
改法
TCK / TMS 继续共用；桥 B 单独给 TDI2 / TDO2，用 bank11 唯一空着的一对 CEP2_8P/N。R6 保留成 0Ω/NC 选项，需要时可跳回菊花链。TCK / TMS 一点分两路走两根 FPC，建议 R3/R4/R7/R8 改 22–33 Ω。
原因
违反契约"每面独立 4 根 JTAG、按面读 IDCODE 判在位"。任一面桥不在位或未上电，整条链断，另一面也加载不了。
S3

SoC：DR1 底板 bank33 / bank11 必须是 2.5 V

整板前提 · 待确认方案
现状
面 A 全部信号在 bank33（CEP1），面 B 在 bank11（CEP2）。LVDS25 输出要求 VCCIO = 2.5 V；边带和 JTAG 直连桥板转换芯片的 2.5 V 侧，也要求 2.5 V。FS03 原厂跳帽只有 3.3 V / 1.8 V 两档。
待确认
板上 H7 / H9（PWR2V5 + GND 两针）是否就是给 FS03 两个 VCCIO 跳帽供 2.5 V 的飞线口？图上没注释，请写明。前提是 S1 先修好。
连带
  • bank11 改 2.5 V 后，2047 屏（LVCMOS33）不能再接 CEP2。
  • CN3 光电开关由 VCC3V3（HT7533）供电，信号进 CEP2_24P：推挽 3.3 V 输出超过 2.5 V bank 的 VIH max（2.8 V）。请确认传感器输出类型，改由 PWR2V5 供电或加分压；开集输出则补上拉。

建议（不阻塞投板）

板内容
桥U18 上下拉：现在 TDI / TMS / TCK（R221–R223）和 TDO（R219）全是下拉。TCK 被拉低功能上可用；按改板单应为 TMS、TDI 上拉到 PWR2V5，TDO 上拉到 VCC3P3，可顺手改。
桥U18 / U19 的 OE# 是 10k 下拉（R220 / R233），常使能、无跳线。下载座在 2.5 V 侧不需要靠 OE 让路，可接受；TI 建议上电期间 OE 保持高，属小风险。
桥下载座 H1（PZ254V-11-06P）脚序 1 GND / 2 TCK / 3 TMS / 4 TDI / 5 TDO / 6 PWR2V5，在 2.5 V 侧，与 U18 不冲突。使用时须拔 FPC，否则与 DR1 的 JTAG 冲突；高云下载器需做 6 针转接线（6 脚作 VREF）。
桥以前提过仍未改：RSTN 的 R171 + TXB0108；CN3 / CN6 旁无去耦；U1 / U2 / U8 的 OE 下拉位标 NC；5 V 入口无保险丝 / TVS；标题栏图名仍写 _1010。
两板FPC 尾部可以不改板，改契约。两块板尾部一致：61 GND / 62 ACK / 63 RST / 64 UART_RX / 65 UART_TX / 66 GND / 67 TDO / 68 TDI / 69 TMS / 70 TCK；座子 XW0525512-702R-001 为 70 导体，71 / 72 是固定脚（接地，72 两边都请确认接地）。两端同名就不会短地，建议把接口契约改成这个实际脚序（原改板单第④项降级）。
两板FPC 线型写进图纸：必须 1↔1 导通。两端是同一颗座子、脚号到网名对应相同；若买成镜像线（p ↔ 71−p），GND 1 / 4 / 7 会接到 TCK / TDO / UART_RX。同面 / 异面取决于座子上接 / 下接与两板叠放，请明确。
SoC发送端 100 Ω/NC 位（R182–R201、R53–R72）必须 NC：接收端桥板已有 100 Ω，再贴是双端接，摆幅减半。
SoC契约要求 SoC 侧 SB_ALIGNED（ACK）2.2k 下拉，图上没有。但中间隔着桥板转换芯片推挽输出，SoC 侧下拉盖不住；下拉实际应做在桥板 GW5A 侧（B 侧）。
SoC24 V 入口（H5 / H6 单针排针）建议加保险丝、TVS、防反接。U1 TPS56A37 输入范围 4.5–28 V（TI 官网），24 V 合法但余量只有 4 V，滑环场合尤其需要 TVS。
SoCTPS56A37 的 MODE 电阻 R73 另一端网络看图不清，按 TI 用法应接 AGND，请确认。CN1 / CN2（B2P-VH）各给一块桥板送 5 V，脚序（2 = 5 V、1 = GND）请与桥板 5 V 入口核对。
SoCFS03 底板 CEP 每根线上有 33 Ω 排阻（R187–R210），40 对都用的话整排换 0 Ω。bank33 上电到加载前的强制上下拉（DS1200 表 2-6），要核 RST（CEP1_23N）在这段时间会不会被拉高、提前放开桥片复位。
SoC网名统一：第二面 DRV2_* 建议改 DR1V2_*；JTAG 的 FPGA_* / FPGA1_* / FPGA2_* 混用，建议统一成 FPGA1_ / FPGA2_。

已确认正确

板内容
桥VCCIO45 回 3.3 V：L7（PWR2V5）标 NC，L3（VCC3P3→VCCIO45）贴片。Gowin 工具实测 3.3 V 下上行 20 对 LVDS 接收、链 4 D0 真差分输出均合法。
桥U19 型号、供电、去耦（C57 100 nF 在 VCC3P3，C58 在 PWR2V5）正确；删掉的 R129–R132（0 Ω 直连）、R173（10k 下拉）由 U19 一组器件接替。
两板SoC FPC1 / FPC2 与桥 FPC2 的 1–70 脚逐脚同名：DR1V_TXP/N0..17、TXCLK、TXCHK、ACK、RST、UART_RX/TX、TDO / TDI / TMS / TCK。
SoC40 对全部 CEPx_kP → TXP、CEPx_kN → TXN，同一个 k，无交叉、无跨对。信号路径上只有 0 Ω / NC，无电平转换（符合契约）。FPC 不走电源。位号无重复；两路 DCDC 反馈分压为 5.0 V 和 2.50 V。
