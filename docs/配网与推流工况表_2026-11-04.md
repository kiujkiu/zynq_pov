# 手机配网与推流工况表 (V1 计划基线, 2026-11-04 用户批)

定案: 无实体按键; 手机不装 App; 贴纸二维码连热点; 屏幕配对码授权; V1 做 P0 + 局域网 + 直连, 互联网和账号放 V2。
第二台主机推流时拒绝, 显示谁在用; 管理员可强制接管。互联网首版 (V2) 只做远程控制和内容下发, 实时推流放后面。

负责: D142 = 板上配网 / D143 = 发现、配对、推流授权 / D144 = 上板和真手机验收。状态写在 进度看板 deliverables.csv。
