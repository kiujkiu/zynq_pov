我们的应用背景

旋转 POV 立体显示。验证板一块：沿用贵司参考板 ICN-P0.9375(BGA)-160×180-60S-V1.0-LVDS 的 LED 阵列与 2260 布局（160×180 点，0.9375 mm 间距，12 颗 2260，3 行 × 4 列，每 2 颗拼一个 80×60 块、行列共用），但把原来"12 颗串一条 mini-LVDS 链"改成"每颗一条独立的 mini-LVDS 链路"（每颗 1 对时钟 + 3 对数据，由 FPGA 直接点对点驱动）。

改独立链路的原因：我们此前在 9 颗级联的样板上遇到"从第 k 跳起往下全部不显示"的前缀型失效，改成一颗一链后每颗都是链路第一跳。

下面问题按对我们的阻塞程度排序，第 1、2 两组会直接决定 PCB 要不要改版，恳请优先答复。

一、60 扫配对模式（最紧急，卡住 PCB 定版）

编程指导 V2.8 §2「级联模式」写明：两颗 ICND2260 可以行列共用驱动 80×96，芯片 A 的行驱动控制第 1–48 行、芯片 B 控制第 49–96 行；§8-16 给了 reg0x04[13:8]=芯片一扫数、reg0x04[5:0]=芯片二扫数、总扫描数为两者之和，§8-17 给了 reg0x08[0] 扫描扩展模式使能。我们的板子是同样的结构，只是 30 + 30 = 60 扫。

我们真正需要的能力只有一条：让一颗芯片在指定的扫描时隙里只输出列电流、完全不开行管。只要两颗芯片在同一时刻只有一颗的行驱动在工作，这个屏就能正常扫描——至于芯片内部叫不叫"芯片一/芯片二"并不重要。所以问题按这个顺序：

  1. 能不能让 ICND2260 在某些扫描时隙完全不开行驱动（行管全关），同时照常输出列电流？ 如果能，是哪个寄存器？
  2. 如果能：这些"不开行管"的时隙位置可以指定吗（例如放在一帧的前 30 个时隙，而不是最后）？§8-16 写的是"扫描数用不满的情况空行必须排布在每颗芯片的最后"——如果这是硬限制，那配对里的第二颗（需要空在前半）该怎么配？
  3. 数据手册首页列了"可编程扫描顺序"这条特性，但编程指导全本没有这组寄存器的说明。能否逐个扫描时隙指定用哪个行管、或指定本时隙不开行管？ 请给寄存器位定义与示例。（顺带：§11 默认表里 0xa6~0xad 是 a5a5 / 1842 / 5a5a / 2184 / a5a5 / 4218 / 5a5a / 8421 这样一组位模式，请问这是不是扫描顺序相关的映射表？）
  4. 这两颗必须级联在同一条 mini-LVDS 链上吗？ 如果每颗接独立链路（每颗都是"第 1 级联设备"，帧头 VHEAD[19:16] 级联芯片数 = 0 表示 1 颗），配对扫描还能不能工作？
  5. 如果必须靠级联顺序来分工：芯片靠什么知道自己是"芯片一"还是"芯片二"（即驱动前 30 扫还是后 30 扫）？手册里没有查到相应的寄存器位；DEVICE[3:0] 的定义是级联序号，独立链路时两颗都是 0。
  6. 退一步：如果空行只能排在最后，我们能否把两颗的扫描相位错开半帧来实现"同一时刻只有一颗行驱动在工作"（两颗都配 30 实 + 30 空，第二颗的 I_SYNC 延后 30 个扫描周期）？I_SYNC 是不是内部扫描计数的起点？帧内相位会不会漂移？
  7. 配对模式下，每颗芯片需要接收的显示数据是"自己的 40 列 × 全部 60 扫"吗？VHEAD[31:24]（扫描行数）与 VHEAD[19:16]（级联芯片数）在独立链路的配对场景下应该怎么填？
  8. 配对的两颗靠什么保持扫描同步？只靠 I_SYNC 每帧对齐是否足够（两颗各自从自己的 DCLK 生成 GCLK，频率相同但由 FPGA 不同引脚输出）？帧内会不会累积偏差？
  9. 编程指导 §11 的默认寄存器表里，0x04 = 0x2d2d（芯片一 45 扫 + 芯片二 45 扫 = 90 扫）、0x08 = 0x5105（bit0 = 1，扫描扩展模式默认启用）——也就是说芯片出厂默认就是配对模式。那么在这个默认状态下，两颗芯片是靠什么分工的？（与上面第 5 问是同一件事）
  10. 我们手上的 2260lvds.xlsx 是 45 扫单颗样板的配置（0x04 = 0x2d00、0x08 bit0 = 0），不含配对模式。能否提供一份 60 扫配对模式的完整寄存器配置示例（最好就是贵司点亮 ICN-P0.9375-160×180-60S-V1.0-LVDS 参考板时用的那份）？
  11. 确认一下我们对数据量的理解：配对模式下每颗芯片接收的行数 = 总扫描数（例如 60 行 × 自己的 40 个像素），而不是自己驱动的那 30 行——因为按 §2 的图，每颗芯片的列驱动要覆盖全部 96（我们是 60）行。对吗？
如果答复是"必须级联"，我们需要在灯板上把配对的两颗用 SDO→SDI 连起来（现在 SDO 全部悬空），这是改版动作，所以请尽早答复。

二、差分端接 RBD / RDC（决定灯板 BOM 与布局）

数据手册 V1.7 P8「mini-LVDS 电气特性」表里有两行：

Module chain 差分匹配电阻   RBD   80 / 100 / 120  Ω
Data chain   差分匹配电阻   RDC  160 / 200 / 240  Ω
  1. 这两个电阻是芯片片内集成的，还是要求客户在外部并接？
  2. "Module chain" 与 "Data chain" 分别对应哪些引脚？（SDI_R1/R2、SDI_G1/G2、SDI_B1/B2、L_CKIP/L_CKIN 各属于哪一类？）
  3. 如果是片内：是否可通过寄存器开关？上电默认是否使能？
  4. 如果要求外接：贵司参考板（RJ45 电缆直接进第一颗芯片）上我们没有看到任何外部端接电阻，这种接法是怎么保证的？
背景：我们按"需要外接 100 Ω"给灯板预留了 48 组端接位，但贵司参考板和我们此前的调试板都没有外接电阻且工作正常，所以需要确认到底加不加。

三、ACK 回读（我们至今一帧合法 ACK 都没收到过）

编程指导 V2.8 P6 引脚表写：ACK_O「级联情况下需接入上一颗芯片的 ACK_I，第一颗 ACK_O 输出所有芯片回传数据」；ACK_I「…最后一颗 ACK_I 可浮空」。

  1. 12 颗都不级联时（每颗 ACK_I 悬空、每颗 ACK_O 各自独立引出），每颗能否正常输出自己的回包？
  2. ACK_I 有无片内上下拉？不使用时建议悬空、上拉还是下拉？（我们打算 100 kΩ 上拉到 VDDD，因为 N12 紧邻 N11(SEL_O)，悬空的 CMOS 输入曾让我们收到大量噪声触发的假帧）
  3. ACK_I / ACK_O 的 VIH / VIL / VOH / VOL 分别是多少？数据手册 P7 的电气特性表里只有 SDO/CLKO 的 VOH/VOL 与 SDI/CLKI 的 IIH/IIL，没有这几个脚的数据。

四、时序与电平参数（决定我们的时钟拓扑与验收判据）

  1. VIC = 1.1 ~ 1.3 V 是绝对最大额定还是推荐工作范围？ 超出上限会出现什么现象（不工作 / 误码 / 损坏）？
    • 我们用的 FPGA（高云 GW5A）差分输出共模典型范围是 1.125 ~ 1.375 V，上限高于 1.3 V。这条决定 12 对时钟是可以直流直连，还是必须加交流耦合 + 共模偏置。
  2. tSTU / tHLD = ¼ tLVCP 的容差是多少？ 数据手册 P9 那两行只填了典型值栏，min / max 都是空的。我们需要一个"数据相对时钟的相位允许偏离多少"的数，否则所有走线等长与 skew 预算都没有验收线。
  3. 数据手册 P9 注释 1：「对于 mini-LVDS 驱动端，传输延时可设置为 1/8 tLVCP、1/4 tLVCP 或 3/8 tLVCP」。
    • 这个设置是否同时移动接收端的采样点？（手册只写了"驱动端"）
    • 是哪个寄存器的哪几位？上电默认值是多少？
  4. 数字输入脚（I_SYNC、RSTN、LVDS_EN、SCL、SDA、DFT_EN）的 VIH / VIL 分别是多少？数据手册 P7 全表没有这类参数，我们目前只能按 CMOS 惯例估算 0.7 × VDDD / 0.3 × VDDD，无法作为设计判据。
  5. VDDD 推荐工作值：电气特性表是最小 2.8 V / 典型 2.8 V / 最大 3.8 V，而绝对最大额定也是 3.8 V；贵司参考板实际用的是 3.8 V。请问官方建议取哪个值？3.8 V 长期工作是否有可靠性余量？
  6. L_CKOP / L_CKON（mini-LVDS 时钟输出）四问：
    • 不做数据级联、只用它做时钟中继时，是否照常工作？
    • 它的 Voc / Vod 的 min / typ / max 是多少？
    • 每跳的传输延时 tPD 与抖动累积是多少？170 MHz 下最大可串几级？
    • 用它做级联时，下一颗的接收端是否仍需外接端接电阻？

五、使用方式与标定

  1. SCL / SDA（IIC）：数据手册引脚表写 E3 = IIC 时钟端、F3 = IIC 数据端，但数据手册与编程指导全文都没有 IIC 章节（无器件地址、无寄存器映射、无时序图）。
    • 这两个脚的实际用途是什么？是否面向客户开放？
    • 不使用时的建议接法？（贵司参考板是每脚各接一只 4.7 kΩ 上拉到 VDDD）
  2. 每色标定值：0x20 / 0x30 / 0x40 三个颜色块里，偏移 +9、+a、+c、+d 四个寄存器在贵司给的配置里三色各不相同，看起来是与本板 LED 正向压降绑定的标定值。这些值是怎么由实测得到的？ 有没有标定流程或上位机工具？换一批 LED 后要不要重标？
  3. DFT_EN、ATEST、GPIO0、GPIO1、SEL_I、SEL_O 这几个"测试用"引脚，不使用时的建议接法是什么？（贵司参考板是全部悬空）
  4. DCLK (D3) 在纯 mini-LVDS 模式下不使用时，建议悬空还是下拉到地？

我们已确认、无需回答的（供参考，避免重复沟通）

  • 寄存器表长度 238 条（0x00~0xED）—— 与贵司一致
