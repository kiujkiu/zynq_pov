# 问询单 (第 2 轮): ICND2260 mini-LVDS 接口 —— 时钟共用与电平

> 2026-10-29。背景：旋转 POV 立体显示，每面 24 颗 ICND2260，每颗独立一条 mini-LVDS 链（时钟 + SDI_B1/G1/R1 三对数据），
> FPGA 直驱（高云 GW5A，LVDS25 / MINILVDS 输出），DCLK 约 166–170 MHz（数据 340 Mbps 双沿）。
> FPGA 引脚不够每颗一对时钟，计划 **两颗 2260 共用一对时钟（1 驱 2）**，数据仍每颗独立。第 1 轮问询单（9-20）未收到书面答复的几条也一并列在这里。

## 一、时钟 1 驱 2 是否支持（最关心）
1. 一对 mini-LVDS 时钟（L_CKIP / L_CKIN）同时接 **两颗 2260** 的时钟输入，是否支持？贵司有没有这样用的参考设计？
2. 推荐拓扑：菊花链（经过第一颗再到第二颗、末端端接）还是 T 型分叉？对分支（stub）长度有没有要求？
3. 时钟输入端的 **输入电容 / 输入阻抗**是多少？
4. 如果不建议 1 驱 2：用第一颗的 **L_CKOP / L_CKON 中继输出**给第二颗做时钟可以吗？中继的传输延时 tPD、抖动、Voc/Vod 各是多少？数据线不级联（每颗独立）时，第二颗的数据采样与中继时钟的相位关系如何保证？

## 二、片内端接（决定我们放不放电阻）
数据手册 V1.7 P8「mini-LVDS 电气特性」：
```
Module chain 差分匹配电阻   RBD   80 / 100 / 120  Ω
Data chain   差分匹配电阻   RDC  160 / 200 / 240  Ω
```
5. 这两个电阻是 **片内** 还是要求 **外接**？
6. **L_CKIP/N（时钟）属于 RBD 还是 RDC？** SDI_R1/G1/B1 属于哪一类？
7. 片内端接是否 **上电后才接通**？（我们断电用万用表在时钟两脚之间量不到 100 Ω）能否用寄存器关闭？上电默认开还是关？
8. 1 驱 2 时，两颗的片内端接并联（100 // 100 = 50 Ω 或 200 // 200 = 100 Ω）——是否需要关掉其中一颗的端接？

## 三、输入共模与幅度
9. **VIC = 1.1 ~ 1.3 V 是绝对最大值还是推荐工作范围？** 输入共模到 **1.375 V**（我们 FPGA 输出共模最坏值）会怎样：正常 / 误码 / 损坏？
10. VID（差分输入幅度）的最小 / 最大值？1 驱 2 后摆幅可能降到约 175 mV，是否仍满足？
11. 是否接受 **AC 耦合 + 外部共模偏置**的接法（时钟对）？

## 四、时序
12. **tSTU / tHLD（= ¼ tLVCP）的 min / max 容差**是多少？（手册只有典型值）——决定数据相对时钟允许的相位偏差。
13. 手册 P9 注 1「驱动端传输延时可设 1/8、1/4、3/8 tLVCP」：这个设置是否同时移动接收端采样点？对应寄存器位和上电默认值？
14. DCLK 170 MHz 下，时钟占空比的要求？

## 五、第 1 轮未答（9-20 问询单）
15. ACK_O / ACK_I 不级联时每颗能否独立输出回包；ACK_I 片内上下拉；ACK 引脚 VIH/VIL/VOH/VOL。
16. 数字输入（I_SYNC、RSTN、LVDS_EN）的 VIH / VIL。
17. VDDD 推荐工作电压（2.8 V 还是 3.8 V），3.8 V 长期工作的可靠性余量。
