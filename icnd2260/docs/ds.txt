                                           ICND2260       PWM 恒流行列合一共阴 LED 显示屏驱动芯片


产品概述                                                 封装
  ICND2260 是专门为小间距和微间距 LED 显示屏
设计的共阴驱动 IC，  它具有创新的行列合一整合架构，                                 Ball Grid Array
采用多种数据传输方式，    让 LED 模组电路设计更简洁，
显示效果更优，彻底解决困扰业界的高对比耦合，跨
板耦合等问题。

特性
   供电电压
    VDDR: 2.8~5V
    VDDGB: 3.5~5V
    VDDD: 2.8~3.8V
   输出电流设定范围
    G: 0.1mA~6.4mAx40 @VDDGB=3.8V
    B: 0.1mA~6.4mAx40 @VDDGB=3.8V                                 BGA
    R: 0.15mA~9.6mAx40 @VDDR=2.8V
   电流精度
    通道间: < ±1%
    芯片间: < ±1.5%
   支持 TTL 或 mini-LVDS 传输模式
    TTL 支持 1，2，3，6 通道传输
    mini-LVDS 支持 1，2，3 通道传输
   PWM 灰度位宽 16-bit
   10-bit 电流增益
   恒流通道数: 120
   行管数: 48 NMOS
   最大支持 16 颗级联
   最大支持 96 扫
   可编程扫描顺序
   LED 开短路侦测并回传
   温度侦测并回传
   FGCLK Max: 600MHz
   FDCLK Max: 25MHz (TTL-DDR), 170MHz(mini-
    LVDS)
   工作温度范围: –40°C to +85°C
   封装: BGA225

恒流特性
ICND2260采用了精确电流驱动控制技术，同一芯片的不同通道间，不同芯片之间的电流差异极小。
1) 通道间电流差异< ±1.0%，芯片间电流差异< ±1.5%。
2) 具有不受负载端电压影响的电流输出特性，如下图所示。输出电流将不随LED顺向电压VF 的变化而变化。

调节输出电流
ICND2260无需外接电阻，可直接通过寄存器配置分别调节RGB输出电流。

红色电流输出 IOUT=IREF*(igain+1)*1.5* color_adj
IREF= reg0x2d[5:4] 00: 0.1mA, 01: 0.2mA, 10: 0.3mA, 11: 0.4mA 默认值 reg0x2d[5:4]=1
Igain= reg0x2d[3:0] 0000:0     1111:15        默认值 reg0x 2d[3:0]=8
color_adj= reg0x29[6:0] 0000000:50%       1111111: 150%      默认值 reg0x29[6:0]=85

绿色电流输出 IOUT=IREF*(igain+1)* color_adj
IREF= reg0x3d[5:4] 00: 0.1mA, 01: 0.2mA, 10: 0.3mA, 11: 0.4mA 默认值 reg0x3d[5:4]=1
Igain= reg0x3d[3:0] 0000:0     1111:15          默认值 reg0x3d[3:0]=f
color_adj= reg0x39[6:0] 0000000:50%       1111111: 150%      默认值 reg0x39[6:0]=85
